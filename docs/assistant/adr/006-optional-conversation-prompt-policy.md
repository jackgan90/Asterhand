# ADR-AST-006：可选的会话提示词策略

状态：部分被 [ADR-AST-007](007-preserve-native-harness-prompts.md) 替代。原生 OpenClaw 默认整段替换的选择已改为保留原生设定并局部补充；其他可选适配与观察契约继续有效。

## 背景

持续聊天复用 harness 的模型循环和历史。默认系统提示词可能描述当前会话未开放的工具，产品需要一致的身份、能力事实和操作表述规则；未来 harness 对系统提示词的支持程度不同。

## 决策

- 独立提示词模块组装版本化产品规则与有效能力事实；会话适配器处理原生注入方式，公共层只保存方式、状态和版本。
- replace、append、unsupported 是支持声明；pending、applied、degraded 是具体轮次的观察结果。缺少覆盖能力或应用失败时继续原生聊天，显示非阻断提示。
- OpenClaw 使用应用自带的可信插件，通过 before_prompt_build 替换纯聊天系统提示词，llm_input 核实实际输入。保留 harness 必需的模型身份上下文；不修改第三方源码或用普通用户消息争夺系统指令优先级。
- 插件源码捕获目录与运行数据分离，后端显式提供受保护的策略文件路径。观察元数据在插件进程内有界保存，通过现有认证 Gateway 的私有只读方法查询；不增加公开 UI 操作或模型工具。每次输入先撤销旧观察，查询失败不复用旧成功，避免磁盘写入失败造成陈旧确认。状态绑定运行时实例、原生会话与轮次，不保存提示词、正文、凭据或隐藏推理。
- 提示词不授予执行能力。首个聊天配置继续关闭工具、管理命令、默认 memory 槽和不受控插件；实际出站工具集合通过原生验证确认。

## 结果

新 harness 可诚实降级，不必伪造 override。模板和能力描述可独立维护；已有默认角色会话按轮次使用当前产品规则，不重写历史。模型行为仍需真实模型验证，配置与钩子单测不能替代实际出站请求检查。

实现范围与复现入口见[功能计划](../../development/features/chat-prompt-interaction/plan.md)，契约见[持续会话设计](../conversations.md)。
