# ADR-AST-007：保留原生 Harness 设定，仅适配产品冲突

状态：采纳；替代 [ADR-AST-006](006-optional-conversation-prompt-policy.md) 中默认整段替换 OpenClaw 系统提示词的选择，其余可选增强、权限与观察契约继续有效。

## 背景

整段产品提示词覆盖会丢失原生人格、身份和行为设定，SOUL.md、IDENTITY.md 等即使由运行时加载也无法传入模型。统一入口需要准确的能力描述，不需要统一抹平不同 harness 的性格和工作习惯。

## 决策

- 所有会话适配器遵循原生优先：保留原生身份、人格、语气、行为与上下文注入；仅针对与 Asterhand 已实现能力冲突的内容做最小适配。
- 优先使用运行时的工具策略和结构化配置生成正确工具清单/定义；其余差异用有明确作用范围的系统补充表达。不复制上游整篇提示词，不按标题/正则删改用户角色文件，不把整段替换当默认集成方式。
- OpenClaw 使用 before_prompt_build 的 appendSystemContext，保留原生系统提示词。产品规则仅校准工具、管理命令/配置入口、持久化和当前界面输出；身份与语气由原生设定决定。角色文件不能扩大实际工具权限。
- 启用隔离聊天工作区的原生 bootstrap 文件初始化；由锁定 OpenClaw 补齐默认文件并加载已存在文件。用户定制内容不被产品模板覆盖，不导入其他 home、节点或工程仓库的设定。未开放的角色/记忆写入仍不可用。
- append/applied 为正常成功；replace 作为兼容声明保留。降级只表示不支持或本轮应用未确认，不把保留原生提示词当缺陷。通过实际模型输入和工具集合验证补充生效，通过集成测试验证原生及定制内容保留。

## 结果

上游人格、角色文件和非冲突行为能随原生版本演进；产品维护一小段能力差异规则。更多原生上下文会增加输入长度，长度以实际请求测量为准。补充规则不提供执行授权，原生文字中的未开放操作不会因此成为可调用能力。
