# ADR-AST-008：提示词诊断与聊天展示分离

状态：接受。

## 背景

提示词注入、应用确认与降级是运行时诊断信息。聊天中动态插入此类提示会打断阅读并改变消息视口，用户无法据此执行有效的聊天操作。

## 决策

聊天窗口完全移除提示词适配状态的标签和提示区。运行时继续验证应用状态、在轮次元数据中保留证据，适配失败继续原生聊天。未来需要诊断入口时在 Web 端独立设计，本次不增加入口。

本决策替代 [ADR-AST-006](006-optional-conversation-prompt-policy.md) 中“显示非阻断提示”的聊天展示要求，保留其可选增强、能力边界及观察机制。发送拒绝、送达未知、生成失败及保存异常仍在聊天中提示。

## 影响与验证

去除提示词状态驱动的 DOM 和布局变化，不改模型输入、工具权限或持久化格式。前端测试检查 pending/applied/degraded/unsupported 均不插入诊断文字；真实 WebView2 测量发送期间消息视口和操作区高度，验证见[完成提醒与发送稳定性计划](../../development/features/chat-completion-attention/plan.md)。
