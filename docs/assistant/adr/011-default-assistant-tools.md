# 默认助手启用受限工具

- 状态：accepted。
- 替代关系：仅替代 [ADR-AST-010](010-local-runtime-capability-boundaries.md) 的默认关闭策略；工作区限制、人工权限管理和原生适配原则保持。

## 决策

未设置过工具权限时，默认助手启用首批受限文件、搜索、记忆和进度工具。普通用户通过“设置 → 助手”的“允许助手调用工具”开关选择关闭或重新开启；不提供独立文件管理、搜索或恢复面板，相关维护能力继续由公共 CLI/MCP 提供。

配置中的非空权限修订表示已有明确或已归一化的策略。缺失工具设置，或只有旧默认布尔值而没有权限修订时，配置层采用开启值和稳定默认修订。人工更改总是生成新修订；已有修订的关闭值在重启、升级和其他设置保存后保持。

默认值只覆盖本批已经实现并限制范围的工具，不能据此启用脚本、网络、外发消息或未来未审核能力。公共 CLI/MCP 和模型不获得权限变更入口。

## 原因与后果

面向普通用户的默认助手应能直接处理自己的文件和记忆，避免安装后看似可用却持续声称没有工具。保留明确关闭选择，避免升级覆盖用户已经作出的决定。权限加载、提示词、原生工具列表和业务服务仍使用同一配置；正在执行或排队时拒绝切换，成功切换从下一轮开始使用新配置。

新安装与未设置过的旧节点会使用受限工具；这不改变可访问目录和执行边界。验证覆盖默认开启、旧默认迁移、明确关闭保持、修订稳定以及纯文本模式回归，见[本机工具验证](../../development/features/local-runtime-tools/validation.md)。
