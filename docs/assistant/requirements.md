# 助手需求

范围：OpenClaw + DeepSeek 及可扩展模型配置边界。关联 R03、R04、R17、R18、R23、C05。

| ID | 要求 |
|---|---|
| AST-01 | A、B 完整节点均有独立 OpenClaw，支持本机自然语言任务 |
| AST-02 | 自然语言明确指定 B 时，通过 Asterhand 提交持久远端任务 |
| AST-03 | 默认 DeepSeek，模型与 provider 可配置，不硬编码进任务核心协议 |
| AST-04 | 本地 Web 按需配置 API key，支持更换、删除、可选测试和重启后读取；启动及非模型入口不要求凭据或模型调用 |
| AST-05 | 普通文件任务无需 coding harness；首版不出现其登录前置 |
| AST-06 | 工具循环复用运行时，任务启动/重试归 Asterhand 唯一管理 |
| AST-07 | Skills/memory 优先复用且本地隔离，后续可导出，不复制活跃数据库 |
| AST-08 | 模型选择按 provider/model/credential_ref/endpoint 表达；仅开放已实现的 provider 与 endpoint 能力，未知值拒绝 |
| AST-09 | 旧节点配置与加密凭据可迁移；模型、凭据、有效运行时选项、源码或依赖变化使旧诊断过期，不阻止本地配置齐全的功能使用；显式选项重启后保留 |
| AST-10 | 节点运行、聊天/模型任务的本地配置状态和手动诊断分开；新请求按功能检查必要配置，直接执行真实请求，不插入预先 LLM 测试 |

验收必须使用真实模型完成本机和远程文件任务；固定回复或纯 FakeExecutor 不满足产品验收。

锁定 OpenClaw/provider 2026.10.7、Node 24.22.1 与默认 deepseek/deepseek-flash。Windows DPAPI、本机密码表单和真实无副作用工具 probe 已实现；每 attempt 独立 agent exec，无长期记忆同步。

## 本机持续聊天

以下为[本机持续聊天](../development/features/local-node-chat/plan.md)的需求；当前源码已接入，工程验证和产品验收分别记录。详细契约由[持续会话设计](conversations.md)维护。

| ID | 要求 |
|---|---|
| AST-CHAT-01 | 快捷输入可显式发起当前节点默认助手的多轮文本聊天，使用节点配置的 runtime/provider/model，支持流式回复 |
| AST-CHAT-02 | 已接受消息由 harness 持久保存；支持新对话、会话列表、最近历史和向前分页，重启后恢复；agentd 只保存绑定/恢复元数据，不维护完整正文副本 |
| AST-CHAT-03 | 创建和发送使用稳定请求身份；可靠接收、送达未知与失败分开；确认丢失先核对，重试保持原目标与身份；未接受草稿仍为内存数据 |
| AST-CHAT-04 | UI 隐藏或崩溃不取消生成；停止请求与实际停止分开；runtime/节点重启后核对在途状态，部分未保存内容明确展示，不自动重跑未知轮次 |
| AST-CHAT-05 | 公共会话接口不依赖 OpenClaw RPC/原生 ID；按能力接入 harness；默认 runtime 变化不改绑旧会话，历史迁移单独设计 |
| AST-CHAT-06 | 会话显式绑定 node_id、默认 role_id 和角色/runtime 配置引用，名称不作身份；预留同机多节点、多角色而不实现其管理功能 |
| AST-CHAT-07 | 普通聊天独立于任务槽，首版工具、代码、skill 和管理命令执行关闭；Conversation/Turn/Task 分离，为后续任务引用保留边界 |
| AST-CHAT-08 | 本地/未来远程共用会话语义，目标节点为权威；事件/历史有界，支持游标失效和状态核对；首版不开放远程聊天 |
| AST-CHAT-09 | 按需启动由节点运行时管理，并发历史与发送共享一次启动；单个请求超时不终止正在恢复的运行时。启动失败保留有界、脱敏的阶段与退出诊断，节点退出取消并回收自有启动 |
| AST-CHAT-10 | 启动期间新建和发送可进入节点持有的有界内存队列；稳定绑定目标与正文，入队和原生接收分别确认。支持取消未派发消息、停止并暂停队列、显式继续及界面重建恢复；队满保留新草稿，退出明确处理待发内容，不自动重放未知发送 |

## 聊天提示词

- AST-PROMPT-01：默认聊天保留 harness 原生身份、人格、语气、行为和上下文设定；版本化产品规则仅纠正与当前有效能力/入口冲突的内容，优先使用原生策略和局部补充。提示词适配为可选增强，支持和实际应用状态分离。不支持或应用失败继续原生聊天，底层保留应用状态；聊天界面不显示注入或适配诊断。提示词不授予工具权限。
