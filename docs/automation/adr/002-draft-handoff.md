# ADR-AUTO-002：显式交接未保存草稿

- 状态：superseded，由[外部客户端直接操作](004-external-clients-without-ui-workflow.md)替代。
- 所属需求：AUTO-21、AUTO-25。
- 替代关系：细化 [ADR-AUTO-001](001-shared-operations.md) 的 UI 草稿边界；普通编辑仍由界面拥有，显式委托期间由节点草稿服务协调唯一编辑权。

## 决策

人类可以将未保存图和普通输入交给已授权 agent。采用显式发布快照、指定主体、短期可撤销编辑租约及修订检查；不开放任意页面内存访问。人类始终能取回最新确认内容，取回后旧写入拒绝。默认只编辑，保存/发送须单独允许并走相同领域操作和收据。

只允许 agent 编辑自己的草稿不能完成中途接手；无所有权约束的双向实时写入会覆盖输入，均不采用。节点只在内存保存有界委托草稿，不因此新增聊天正文持久库。详情见[草稿交接设计](../draft-handoff.md)。

脚本选择维持直接提供已知路径与可用性检查，不新增目录浏览；这一边界不影响脚本图编辑和执行。
