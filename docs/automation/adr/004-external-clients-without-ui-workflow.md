# ADR-AUTO-004：外部客户端直接操作，保持原有用户体验

状态：accepted。此决策替代 ADR-AUTO-002 和 ADR-AUTO-003 中的产品内交接流程。

用户在 Codex 等外部客户端用提示词分配工作。CLI 与 MCP 连接当前用户的 Asterhand 节点，调用现有业务服务。多个客户端通过业务对象、窗口 ID 和修订区分目标。人类无需在 Asterhand 中创建或选择 agent。

已保存对象直接访问所属服务。未保存内容只存在于窗口，使用[内部编辑器接口](../draft-handoff.md)处理。Web 复用现有事件流，快捷输入复用原宿主通信。内部接口按请求读取普通字段、更新原编辑器或调用原有提交动作。人类的编辑、发送、保存和快捷键保持原样。敏感设置继续通过原人工入口处理。
