# 读取和修改窗口里的未保存内容

已保存的图、运行、消息和任务可以直接操作。对只存在于打开窗口中的内容，CLI/MCP 使用同一组草稿操作。窗口仍负责输入、选择、撤销、校验、提交和发送。

`drafts.list` 返回打开的编辑器 ID、种类和业务目标。按命令 ID、任务和回答 attempt、会话 ID 或设置组找到目标。多个窗口同时编辑同一对象时，由调用者指定窗口。关闭或切换目标后，重新列举，旧 ID 不会指向新对象。

`drafts.get` 向窗口读取普通字段和修订。图返回当前编辑状态，包括未完成的输入。`drafts.update` 携带读到的修订和完整普通字段，更新原窗口中的内容。`drafts.commit` 携带修订，调用原编辑器的图保存、任务提交/回答或快捷聊天发送操作。节点设置提交只构造普通字段的 patch，人工表单中的密钥、删除密钥开关和配置地址不会进入请求。桌面草稿暂存热键配置，主题和语言使用独立的即时设置操作。

Web 窗口通过已有事件流接收请求，仅按请求返回内容。快捷聊天在宿主就绪后通过已有的受限本机通信按需转发。隐藏窗口只在处理请求时唤醒渲染器，完成后继续休眠，窗口不显示或抢焦点。任务目标或会话切换后，返回同一对象也需重新取得编辑器 ID。连接和等待有界。窗口关闭、修订冲突、正在组字或提交在途时返回状态。已经分派但未得到确认的写入按未知处理，使用原操作身份核对。节点在分派前记下这次保存、任务或聊天的业务请求 ID；窗口关闭后可据此核对业务收据，缺少执行证据时保留未知状态。
