# 长期文档独立于临时执行环境

- 状态：accepted
- 日期：2026-10-25
- 关联需求：DEV-07、DEV-10、DEV-11
- 补充：[文档同步与规模约束](001-documentation-and-size.md)

## 背景

将临时功能编号、个人目录、候选摘要和仅本机存在的报告写入仓库，会使后来维护者无法理解或复现引用。开发执行记录与长期产品文档具有不同的生命周期。

## 决定

长期文档按功能命名并描述当前需求、契约、设计原因和操作方法。验证说明引用受版本控制的测试源码、前置条件、复现命令和预期结果；引用文本直接说明目标含义。

原始执行日志和截图保存在忽略目录，发布所需证据随对应版本发布物归档。长期文档不包含本机绝对路径、临时进程与设备快照、会话授权流水或仅本机可达的证据链接。示例参数必须说明含义，生成路径必须给出生成方法。

requirements/design 维护当前有效状态，ADR 保留决策及替代关系，Git 历史保存变更过程。功能目录使用语义名称，文档收尾检查链接目标是否进入版本控制。

## 影响与验证

代码、测试、操作指南和模板应同步遵守该规则。审查时以新克隆仓库的读者为准：读者应能理解链接内容并按描述运行检查，而无需作者机器或历史聊天。平台支持和正式版本验收结论可以保留，但不能用临时执行流水替代可复现说明。
