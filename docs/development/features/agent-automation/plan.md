# 统一自动化、CLI 与 MCP

状态：实现、工程验证、独立审核及用户验收已完成。

目标和验收标准见[三个入口的实施范围](shared-entrypoints.md)。UI、CLI 和 MCP 调用命令、会话、任务和设置的同一领域服务。Web 页面和快捷输入保留原有呈现与交互。

对应[自动化需求](../../../automation/requirements.md) AUTO-01—25，以及执行器、助手、任务、节点、Web、安装和开发治理中的自动化要求。

1. 已建立[公共操作定义](../../../automation/design.md)、本机通道和两种客户端。
2. 图、运行、日志、会话、任务、普通设置及节点控制已接入并登记到[日常覆盖清单](../../../automation/coverage.md)，支持批量读取和执行。
3. 已通过[编辑器内部接口](../../../automation/draft-handoff.md)支持续改未保存内容，保持人工输入、发送及保存行为。
4. 工程回归、实际 CLI/MCP 客户端、Edge 页面和隐藏 WebView2 宿主检查已通过，独立审核的已确认问题均已修复并通过复审。复现方法与专项环境边界见[验证说明](validation.md)。

认证、凭据、加密配置和配对保留人工入口。远程持续聊天和远程脚本执行属于尚未实现的产品能力。CLI/MCP 示例见[使用指南](../../../automation/usage.md)。

## 文件和函数规模

编辑器请求转发、目标检查和各业务适配按职责分文件，手写文件保持在 1000 行以内。已有的长函数主要处理节点启动、任务状态变化以及与窗口的消息分派，依赖现有初始化和清理顺序。本次只在相应步骤调用业务服务或转发编辑器请求，保留相关状态集中处理。日志编码表由生成器维护，按生成文件检查。
