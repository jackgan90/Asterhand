# UI、CLI 与 MCP 共用业务操作

本文定义[自动化计划](plan.md)的实施范围和验收条件。

用户在 Codex 等外部客户端配置 Asterhand 的本机 MCP 服务，或让 agent 调用 CLI，并在提示词里指定对象和操作。命令、脚本图、聊天、任务和设置仍由各自已有的业务服务处理。CLI 与 MCP 共用操作定义、参数检查、服务和结果。批量操作组合这些已有能力。

## 人类界面

Web 页面、快捷输入窗口及操作行为保持本功能开发前的体验，不增加自动化设置页、agent 列表、草稿交接控件或授权勾选。操作已保存对象时，无须打开页面。CLI/MCP 使用本机当前用户的节点连接，不要求在 Asterhand 里创建或选择 agent。凭据、配对和加密配置继续使用原来的人工入口。

## 未保存内容

未保存输入由当前窗口持有。仅在内部登记已打开的编辑器及其目标，外部工具可以按编辑器 ID 读取普通草稿、替换内容或提交。读取时取窗口的实时内容，编辑时检查目标和读到的修订。窗口关闭、目标变化或处在输入法组合状态时返回明确结果。不会保存一份供其他 agent 接手的私有草稿副本，也不设置编辑租约。

覆盖命令与图、快捷聊天、任务输入和回答、节点及桌面普通设置。图编辑使用现有编辑状态和历史。提交复用对应业务的保存、发送或任务提交操作。来自其他窗口的未保存密钥等敏感字段不能进入接口。提交结果只更新仍然对应同一目标和修订的窗口，不能用旧响应覆盖用户后续输入。

## 验收

- Web 和快捷输入的页面结构、样式、按钮、键盘和提交交互与功能前一致。常规打开页面、聊天、编辑图和保存不依赖 agent 客户端在线。
- 不配置 agent 名单，从 CLI 和真实 MCP 客户端操作同一隔离节点，得到相同的图、运行、日志、会话、任务和普通设置结果。
- 在原编辑器输入未保存内容，从 CLI/MCP 读出、修改并提交。原窗口看到相同内容，整个过程无需用户点击额外控件。
- 通过业务目标找到打开的编辑器。重名或多个窗口时返回可区分的编辑器 ID；窗口关闭、重开或切换目标后，旧 ID 和修订不能修改新内容。
- 人工和外部入口同时提交同一修订时，沿用该编辑器已有的提交状态与业务收据，只接纳一次。编辑普通设置时，另一个字段里尚未提交的密钥既不被读取也不被保存或清除。
- 两个调用者操作不同对象无需协调。对相同对象使用已有修订和运行状态检查，返回冲突后由调用者决定下一步。断线后不重复执行已接纳的保存、发送或脚本运行。
- 覆盖表约束新增日常业务操作同时提供 CLI/MCP，与 UI 共用业务规则。产品验收检查实际常用入口，不以静态登记或模拟宿主代替端到端验证。
