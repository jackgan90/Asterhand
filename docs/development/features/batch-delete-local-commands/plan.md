# 本地命令多选与批量删除

## 范围与需求

Web 本地命令列表通过“新建”同一行的“管理”进入多选，默认隐藏复选框、全选和批量删除控件；点击“完成”退出管理。管理模式提供独立多选、全选/取消全选及确认后批量删除。关联 EXEC-CMD-03/13/17、WEB-CMD-16、AUTO-02/03/12/13/15/24；涉及执行器、Web 和自动化领域。删除注册及可清理运行记录，保留脚本，不增加远端能力。

## 设计

- 工具栏以普通描边显示带加号的“新建”和“管理”；仅管理模式的“完成”高亮。刷新为搜索框右侧图标，带本地化标题与无障碍名称，读取期间禁用，结束后恢复。
- 管理模式默认关闭；完成或关闭窗口清空勾选并隐藏批量控件，保持编辑草稿和未知请求身份。提交中禁止切换，语言切换及后台刷新保留模式。
- 编辑对象与删除集合分离；搜索保留选择，全选固定已加载的完整目录，确认显示总数及搜索外范围。
- Web 专用同源适配接口每次最多 32 项，逐项调用公共 `commands.delete`。页面顺序分块，选择数量不受单请求限制。
- 固定命令 ID、对象修订和操作 ID；只显示失败、未提交和结果待确认的逐项提示；成功后移除列表项，不留成功提示。部分失败不回滚成功项。传输中断停止后续块，未知项保留原身份供显式重试核对，不自动换修订或重放。
- CLI/MCP 复用 `commands.list` 分页读取、`batches.submit` + `commands.delete` 和 `batches.get`；沿用已有 schema、错误、权限和恢复规则。
- 删除成功且包含当前编辑对象时清空表单；其他草稿、历史、选择和结果在后台刷新及语言切换时保留。

## 验收与验证

Node 行为测试覆盖多选、全选、取消、筛选、超过 32 项分块、部分失败、网络中断、重复点击、语言切换和草稿保留。Go HTTP/公共操作测试覆盖注册存储、运行占用、修订冲突、重放、认证/CSRF、批次容量与权限等价。运行国际化、文档链接、Go 回归及构建检查。源码入口、复现步骤和支持边界见[验证说明](validation.md)。

人工验收：打开本地命令，确认默认没有批量控件；点击“管理”后多选/搜索/全选并删除，点击“完成”确认控件隐藏且再次进入没有勾选，核对剩余列表、逐项结果与脚本文件；运行中的命令应保留。

## 状态

实现与本机用户验收已完成，包含批量删除、管理模式、成功提示精简及工具栏样式调整。244 项前端回归、国际化、定向 Go 回归、文档链接和应用构建通过；真实 Edge 的双语双主题与批量删除交互验证通过。完整 Go 回归此前受环境权限限制，尚未补跑全量；公共 CLI/MCP 跨进程及其他环境专项按验证说明单独确认。

## 规模评估

新增生产模块与改动的手写文件均低于 1000 行；词表维持单一权威字典，两份前端词表属生成代码。现有 `localCommands` 工厂超过 100 行，内部表单、图历史、会话代次和状态轮询共享同一生命周期；本次将独立选择/批量状态放入新模块，经窄回调连接表单，不展开现有控制器重构，保持草稿及恢复规则。新增删除处理器和提交函数均小于 100 行。选择模块工厂包含管理显示、选择集合和批量收据的局部函数，超过 100 行；这些函数共享同一生命周期，管理切换保留未知请求身份，继续放在单一模块便于检查，不拆成跨模块共享状态。
