# 聊天展示与桌面窗口体验

状态：实现、相关工程检查与独立审计修复完成，本机日常聊天与桌面交互用户验收通过。多屏/DPI、Explorer 恢复、故障与成本等专项边界见[验证说明](validation.md)。

## 目标与范围

减少无行动价值的常驻提示，提供动态回复反馈、离线数学公式展示，以及可拖动、可从系统任务栏返回的聊天窗口。关联 R02、R03、C08、WEB-CHAT-03/05/09—12、INST-28。依据：[Web 需求](../../../web/requirements.md)、[Web 设计](../../../web/design.md)、[安装需求](../../../installation/requirements.md)、[安装设计](../../../installation/design.md)及[桌面窗口决策](../../../installation/adr/008-chat-window-desktop-presence.md)。

本次实现：

1. 删除输入 placeholder、“草稿仅保留在本次运行中”“回复完成”及 Esc 说明的后半句，保留需要用户处理的异常。
2. “正在回复”后一个点、两个点、三个点按 400 ms 步长循环；正常完成清空，隐藏停止，减少动态效果时静态展示。
3. 固定版本 KaTeX 随包交付，支持行内与块级 LaTeX、流式未闭合回退、安全与资源预算。
4. 顶部品牌及空白区域可拖动；按钮、正文、输入区可正常操作；调整高度和 DPI 不丢失用户位置。
5. 窗口失焦保持打开，移除固定按钮；显示时提供任务栏入口，显式隐藏时移除，点击任务栏恢复并激活已有窗口。
6. 共用前端及平台中立窗口语义，Windows 实现系统能力，macOS/Linux 保留适配边界。

非目标：新桌面框架、富文本输入、完整 TeX 文档编译、远程资源、窗口大小自由调整、跨重启位置持久化、新聊天后端、多节点聊天、macOS/Linux 实现及验收。

## 设计

### 展示与状态

状态规则依赖轮次 delivery/run/persistence 字段。正常 completed 不产生成功标签；保存待确认、拒绝、未知送达、失败及停止保留相应状态。静态标签与动画点分开，点不进入读屏状态播报；动画不增加网络轮询，隐藏和销毁停止。输入上限等编辑错误仍使用原提示区，但正常编辑后清空，不恢复常驻草稿说明。

### 数学公式

资源边界：自定义宏定义/重绑定不在支持范围，直接保留源码，避免短定义放大为大量排版工作；KaTeX 内置数学命令保留。每次消息窗口绘制最多处理 8192 个未缓存公式输入 UTF-16 code unit，失败尝试计入预算，输出节点预算耗尽后跳过排版。单美元未闭合片段按行保留原文。

原始消息仍为正文权威。只在渲染时解析 `\( … \)`、`$ … $`、`\[ … \]`、`$$ … $$`；美元行内公式要求紧邻非空内容且不把普通价格对识别为数学。先识别代码和公式，再处理 Markdown，代码始终可按原样复制。闭合公式按源码和展示模式缓存，未闭合、语法错误、不支持或超限公式回退为可选中的源码。长公式在消息内滚动。

KaTeX 以独立静态依赖记录版本、来源、完整性与许可证，脚本/CSS/字体本地加载。只允许渲染器创建受控公式节点，禁任意消息 HTML、URL 与资源访问；`trust: false`、有限 `maxExpand`/`maxSize`、独立宏状态，以及每条消息公式数量/长度和缓存预算共同限制膨胀。现有整条消息的富文本回退阈值继续生效。补本地字体 CSP/MIME/白名单，真实 WebView2 验证排版和无外部请求。

### 窗口与位置

位置记录只由原生用户移动结束更新；展开、折叠、工作区修正与隐藏均不回写临时受约束位置。高度缩回后重新以保存的用户锚点布局，当前工作区仍负责限制最终可见范围。

平台宿主处理拖动手势、原生激活、系统入口和位置；前端只声明标题拖动区域与排除区域，不传递 Win32 消息或任意屏幕坐标。Windows 使用 WebView2 原生非客户区拖动支持，系统负责移动循环。位置管理区分首次放置、用户拖动、内容高度调整、显示器/DPI 变化。每个显示器保存本次 UI 生命周期内的位置；同屏重新呼出恢复，跨屏呼出使用目标屏记录或默认位置。超界时约束到工作区，屏幕移除后回退到有效屏幕。程序控制的 resize 不覆盖用户位置；不持久化系统坐标。

同一聊天窗口承担任务栏入口，不新增代理窗口。显示/激活与快捷键 toggle 分开，未激活时不隐藏、不置顶；最小化保留任务栏按钮，任务栏激活恢复。Esc、同键、Alt+F4 和系统关闭窗口只隐藏，不退出节点、不取消生成。隐藏后下次呼出恢复正常窗口，后台完成不抢焦点。系统锁屏等已有安全隐藏路径保留。手动固定的启动图标由系统管理。

公共层保持行为契约，不要求其他平台提供 HWND、任务栏位标志或绝对屏幕移动；macOS 后续适配应用级 Dock/激活策略，Linux 后续适配窗口管理器/合成器与真实输入手势。资源清单和数学模块不绑定 WebView2；当前未实现平台继续 unsupported。

## 规模与交付

新增公式解析/预算与原生位置职责使用独立模块；手写改动文件均低于 1000 行，不拆分超限文件。第三方 KaTeX 分发文件独立分类，不手工修改上游代码，不计入手写文件阈值。`chatPanel` 为超过 100 行的装配闭包，内部函数共同持有会话/草稿代次和异步保护状态，沿用现有内聚例外；新增展示规则独立放在状态视图，避免将闭包状态拆成跨模块共享可变对象。`TestNativeChatPanelWorkflow` 为超过 100 行的连续原生交互场景，依赖同一宿主、会话 fixture 和先后操作，保留便于核对完整时序；拆分独立测试会丢失场景关联。其余新增函数未超 100 行。

验证命令、前提与平台限制见[验证说明](validation.md)。原始日志和图片写入执行者指定的忽略输出目录；不把本机证据路径写入长期规范。更新领域文档、导航、路线图、依赖分发说明与测试入口，文档本地链接覆盖新增可交付文件。
