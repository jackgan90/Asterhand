# 聊天运行时启动诊断与恢复

## 范围

修复升级或重启后首次打开已有会话、发送消息时的运行时启动失败。关联 [持续会话需求](../../../assistant/requirements.md) 与 [会话设计](../../../assistant/conversations.md) 的按需启动、历史恢复、草稿保留和未知发送不重放契约。

本次实现有界启动诊断，定位实际启动阻塞并修复对应生命周期或环境处理，补充真实固定运行时的恢复验证。保持现有模型与工具权限、持久收据和消息去重契约。模型探测、自动重发、依赖升级和修改用户原始数据库不在范围内。

## 设计与验收

- 记录启动阶段、耗时、连接结果与进程退出原因；只持久化白名单结构化字段，不保存原始 stdout/stderr、令牌、模型凭据、提示词或聊天正文。
- 诊断有大小与保留数量上限，诊断写入失败不得影响聊天或掩盖原启动错误。
- 用固定安装依赖和隔离状态复现启动恢复，区分首次创建与已有数据库恢复；保留原始数据，复现程序只操作隔离快照。
- 取消、关闭与并发历史/发送不得导致重复消息或遗留自有进程。真实未知发送继续核对原身份。
- 验证启动失败原因可定位、修复前失败用例修复后通过、正常只读历史与受控模型发送通过。

## 根因与修复

原启动操作继承第一个历史/发送调用者的 context，并持有启动门直到结束。调用者取消或截止时间到达时会关闭自有进程；等待中的下一请求随后重新启动，在剩余请求预算内重复恢复。旧会话留下的进程租约还会触发原生数据库完整性检查，增加冷启动工作量。固定原生运行时的短历史请求取消场景可复现旧逻辑启动两次。

启动现在由 `ConversationRuntime` 持有一次共享操作，并使用独立 180 秒回收预算。等待者取消只退出等待；后续请求复用正在启动或已就绪的进程。启动结果发布后重新核对配置摘要，配置变更不采用旧实例；节点退出取消并等待启动完成或进程回收。失败的启动向所有现有等待者返回同一结果，下一次访问才开始新尝试。未派发消息仍可明确拒绝，已派发消息沿用原收据核对。

`conversation_startup.go` 负责启动所有权与共享等待，`conversation_diagnostics.go` 负责白名单过滤、预算和两份报告保留，`conversation_process.go` 负责进程与管道。Gateway 私有桥只转发有预算的启动输出，不向公共聊天接口暴露原始日志。领域行为及诊断字段见[会话设计](../../../assistant/conversations.md)。

状态：实现、工程验证及本机聊天使用验收通过。固定原生运行时对照验证旧逻辑重复启动、修复后复用一次启动；受控模型发送、重启历史、诊断脱敏和相关回归通过。故障注入及跨环境专项保留独立验证边界。

## 验证方式

使用 [测试指南](../../../../tests/README.md) 中的固定 Node/OpenClaw 原生会话测试，补充以下用例：

- [共享启动测试](../../../../internal/executor/conversation_startup_test.go)：首个等待者取消、同时等待、失败后显式重试、配置变化与关闭回收。
- [诊断测试](../../../../internal/executor/conversation_diagnostics_test.go)：密钥/正文哨兵、超长日志、阶段白名单、历史报告过滤、磁盘写入失败。
- [原生恢复测试](../../../../internal/executor/conversation_recovery_integration_test.go)：使用固定 Node/OpenClaw，令第一个只读请求在 500 ms 截止，随后创建会话须复用同一次启动；回收进程再打开原会话，验证绑定与只读历史。该用例不用模型凭据。
- [原生聊天测试](../../../../internal/executor/conversation_integration_test.go)：本地受控模型两轮消息、重启后读取正文、角色文件保留与无工具权限。

常规命令为 `go test ./internal/executor ./internal/conversation ./internal/quickinput ./internal/app`。原生用例设置 `ASTERHAND_CHAT_RUNTIME=1`、`ASTERHAND_CHAT_NODE=<固定 node 可执行文件>` 和 `ASTERHAND_CHAT_ENTRY=<固定 openclaw.mjs>` 后执行 `go test ./internal/executor -run 'TestNativeConversation(StartupSurvivesReadTimeout|Bridge)$' -count=1 -v -timeout 8m`。路径必须指向依赖清单锁定的安装；测试自行创建隔离数据目录，不覆盖实际安装或使用现有凭据。

原始运行证据仅存放于忽略目录。已有用户状态的复现只使用 SQLite 只读备份和重定位后的隔离副本，不作为测试夹具提交。快照恢复证明该副本可恢复；现场最初的磁盘/进程调度耗时不由后续测试回溯测量。真实在线模型、物理桌面和实际升级后用户验收单独记录。

## 规模评估

本次新增模块按启动生命周期、诊断和测试职责独立组织，新增及修改的运行时代码文件均低于 1000 行，新增函数均低于 100 行，无需超限文件拆分。
