# 前端信息精简与显示修复

降低普通用户的理解成本：状态用颜色和图标表达，文字只在需要处理时出现；技术细节默认收起；每个区域只保留一个主操作。修复几处显示缺陷。任务、命令、聊天、日志读取等功能和接口保持不变。

## 基本信息

- 目标：Web 管理页、快捷面板和日志窗口只突出重要信息；设置项按用途归类；修复脚本图编辑器语言、日志窗口前台、面板圆角和开关错位问题。
- 状态：第一阶段实现、工程验证、用户验收和独立评审复审完成。第二阶段（脚本图编辑器交互改造）实现、工程验证、用户验收和独立评审复审完成。
- 需求：[Web 需求](../../../web/requirements.md) WEB-UX-01—06；同步调整 WEB-11、WEB-GRAPH-05/06、WEB-CHAT-09、WEB-CHAT-15 的表述。
- 设计：[Web 设计](../../../web/design.md)的“视觉与文案”“设置结构”“托管命令和日志窗口”“持续聊天面板”各节；日志窗口前台规则见[托管命令设计](../../../executors/managed-local-commands.md#日志读取与窗口)。
- ADR：无新增架构决策。

### 第二阶段：脚本图编辑器节点式交互

需求：[Web 需求](../../../web/requirements.md) WEB-GRAPH-08—10，同步调整 WEB-GRAPH-01。权威设计见 [Web 设计](../../../web/design.md)的“脚本图编辑器交互”一节。图数据（节点、连线、坐标、并行数）、前后端校验、保存接口和运行锁不变。

| 用户问题 | 方案 |
|---|---|
| 编辑器太小 | 命令对话框加宽到 `min(1280px, 96vw)`；画布与右侧属性面板并排，画布高度约 `60vh`；“全屏编辑”铺满窗口，Esc 先退出全屏；“适应视图”缩放并居中全部节点，加载命令时自动执行 |
| 添加/删除步骤要点按钮 | 画布空白处右键或双击即在该位置添加步骤；步骤右键可重命名、选择脚本、删除；选中后按 Delete 删除；工具栏保留“添加步骤” |
| 连线要靠下拉框 | 步骤左右有输入/输出端口，从输出端口拖到另一个步骤即连线，拖动时合法目标高亮、非法目标变暗（复用 `edgeIssue` 判断重复与成环）；点击连线选中，Delete 或右键删除。去掉“选中节点连接到 / 已有连线”两组下拉 |
| 改名要去文本框 | 双击步骤或按 F2 原地改名，Enter 确认，Esc 取消 |
| 关联脚本在下方 | 右键“选择脚本…”直接打开文件选择；步骤卡片第二行显示脚本文件名，未设置时显示警示 |
| 超时、参数在底部 | 右侧属性面板跟随选中步骤：名称、脚本；工作目录、步骤超时、固定参数收进“更多设置” |
| 其他 | 空白处拖动或中键拖动平移，Ctrl+滚轮缩放（以指针为中心，40%—200%），普通滚轮仍滚动对话框；方向键微调选中步骤位置；“最多同时运行 N 个步骤”放在工具栏；长说明改为画布底部一行操作提示 |

模块划分：`graph-editor.mjs` 负责状态与对外接口（`load` / `read` / `setLocked` / `relocalize` 不变）；`graph-canvas.mjs` 负责视图变换、步骤与连线绘制、拖动与连线手势；`graph-inspector.mjs` 负责属性面板；`graph-menu.mjs` 负责右键菜单。锁定（运行中）时只允许查看、平移和缩放。

第二阶段验收：

1. 右键空白处添加步骤、右键步骤重命名/选择脚本/删除、双击改名、Delete 删除步骤和连线均可用；开始/结束不可删除、不可改名。
2. 从输出端口拖到其他步骤可连线；重复连线、成环、连到“开始”或从“结束”连出被拒绝，拖动过程中目标即显示是否可连。
3. 平移、Ctrl+滚轮缩放、适应视图、全屏编辑可用；全屏下 Esc 只退出全屏，不关闭对话框。
4. 属性面板随选中步骤切换，未保存的输入在切换语言后保留；运行中锁定时不能修改图。
5. 保存后的图与改版前格式一致，已有命令可正常打开、保存和运行。
6. 中英双语 × 深浅主题界面核对通过。

## 设计要点

| 方面 | 决定 | 原因 |
|---|---|---|
| 语言初始化 | 本地化控制器完成首帧语言恢复后，主入口立即调用一次各视图的 `relocalize()` | 恢复语言时尚未订阅语言事件，运行期创建的文字停留在默认语言 |
| 日志窗口前台 | 窗口先确保显示，再请求成为前台。快捷面板宿主在请求打开日志前调用 `AllowSetForegroundWindow(ASFW_ANY)`，日志窗口因此可直接激活；系统拒绝激活（例如从浏览器打开）时保持显示并闪烁任务栏。不使用 `AttachThreadInput` 关联其他线程的输入队列 | 打开请求经节点服务转发，节点服务不在前台，授权会被系统拒绝；浏览器无法授予前台权限。关联输入队列会让日志窗口线程依赖前台程序处理消息，前台程序卡住时日志窗口随之卡死 |
| 面板圆角 | 快捷面板窗口请求系统圆角（Windows 11）并设置与主题一致的边框色；页面不再绘制圆角，系统不支持圆角时页面保留直角边框 | 页面圆角无法裁剪原生窗口，四角会露出背景 |
| 主题保存 | 主题从快捷键表单移出，点选后立即调用现有桌面设置接口：沿用当前已生效的开关和快捷键，只改主题；成功后同步表单基线，失败时恢复原主题并显示原因 | 主题同时作用于网页和面板，与快捷键无关；语言已是立即生效 |
| 状态表达 | 命令与节点状态统一映射为 running / succeeded / failed / interrupted 等图标和颜色，文字保留在 `title`、`aria-label` 中 | 屏幕阅读器和悬停仍能获得完整文字 |
| 日志分页 | 仍调用日志读取器现有的 `previous` / `next` / `latest` 导航，只改变触发入口；去掉“最早日志” | 读取协议和分页语义不变 |
| 日志编码 | 编码改为窗口级设置，同时作用于所有分屏 | 分屏独立编码几乎无实际用途，重复控件干扰阅读 |
| 合并日志来源标签 | 按行标注来源；每个来源（节点 + 流）维护未结束的行，被其他来源打断后在新行继续，只结束该行的换行不再显示为空行。标签写入每个数据块的文本（每块一次原生替换），每块仍只有一个元素，元素数量受读取器原有的帧数和字符预算约束；代价是标签与正文同色，复制时包含标签 | 原实现按帧加标签：文本与换行分帧写出时，标签出现在行尾，并多出只有标签的空行。若每行单独建标签元素，密集短行会使元素数量随行数膨胀（8 屏 × 128 KiB 的 `x\n` 约百万个元素） |
| 查看方式 | “全部”只显示本次合并日志；“运行中”自动展开运行节点；“自选”时点击节点切换显示，仍可跨实例最多八屏 | 原下拉内三种模式混合勾选，理解成本高 |
| 设置保存 | 节点设置仍是一个表单和一个保存接口；保存栏在有修改时提示“有未保存的修改” | 保存语义不变，只让用户知道保存会提交什么 |

## 实施与文档同步

- 更新 Web 需求、Web 设计、托管命令设计和脚本图设计中的相关表述；国际化文案在 `internal/i18n/locales/*.json` 修改后重新生成，删除了不再使用的词条（字节位置、跟随状态、分页按钮、上次刷新等）。
- 原生改动限于快捷输入/日志宿主窗口层：`internal/quickinput/` 中窗口外观（`surface_frame_windows.go`）、前台激活（`foreground_windows.go`）和图标资源白名单，不涉及节点服务业务逻辑。
- 与评审方案的差异：
  - 快捷面板保留“执行”按钮。它在命令不可启动（运行中且不允许同时执行）时变灰，是唯一的可启动提示。
  - “送达待确认，正在核对”保留原文案，因为 WEB-CHAT-06/14 规定了这一表述。
  - 日志编码改为窗口级设置，分屏不再各自切换编码。
  - 快捷面板和日志窗口的图标使用随包 SVG（`internal/quickinput/assets/icons/`）作为 CSS 遮罩；快捷输入的 CSP 不允许 `data:` 图片。

## 规模

- 生成的词表模块（`web/i18n-catalog.mjs`、`internal/quickinput/assets/i18n-catalog.mjs`）为生成代码，不计入规模评估。
- 其余变更文件均低于 1000 行（最大为 `web/style.css` 约 770 行、`internal/quickinput/surface_windows.go` 约 460 行、`web/desktop-settings.mjs` 约 470 行）；第一阶段新增函数均低于 100 行。
- 第二阶段：`graph-canvas.mjs` 约 280 行、`graph-editor.mjs` 约 205 行。两者的外层工厂函数（`graphCanvas`、`graphEditor`）超过 100 行软上限：它们沿用本仓库 Web 模块的闭包工厂写法，外层函数只声明共享的视图/选中/锁定状态和若干内部函数，内部函数均低于 100 行。画布的视图变换、步骤卡片、连线手势共享同一组状态（视图、卡片表、拖动中的连线），再拆成多个模块需要把这些状态做成共享对象或大量回调，可读性反而下降；属性面板和右键菜单已独立成模块。后续若加入框选、多选或撤销，再评估把手势处理拆出。

## 验收条件

1. 中文设置下打开命令编辑，脚本图编辑器所有文字为中文；切换语言后原位更新。
2. 日志窗口未创建、已创建但失焦、已最小化三种情况下点击“查看日志”，窗口均显示出来：从快捷面板点击时成为前台窗口；从浏览器点击时，若 Windows 拒绝激活，窗口保持显示并闪烁任务栏。
3. Windows 11 上快捷面板四角为系统圆角，无直角背景露出；深浅主题边框颜色与面板一致。
4. 快捷面板命令行可通过图标区分运行中、成功、失败、中断，悬停可见文字；查看日志、停止、管理命令可用。
5. 日志窗口不显示字节位置和跟随状态；向上滚动后出现“回到最新”，点击恢复跟随；可读取更早和后续输出；编码切换作用于所有分屏；只有一次运行时不显示实例选择。
6. 设置分为五页，主题在“通用”中点选立即生效且刷新后保持；快捷键保存不改变主题；顶栏登录后不显示语言下拉。
7. 命令管理、任务提交/回答/取消/核对关闭、配对与解除配对、设置保存、模型测试的行为与改版前一致。
8. 中英双语 × 深浅主题的 2 × 2 界面核对通过，窄屏可操作。
