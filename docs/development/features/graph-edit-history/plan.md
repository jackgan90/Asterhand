# 脚本图编辑历史与撤销重做

状态：实现与工程验证完成，本机用户验收通过；已确认切换实体中文输入法设置节点名称及重命名正常。关联 [WEB-GRAPH-11—13](../../../web/requirements.md)，权威交互见 [Web 设计](../../../web/design.md)，图格式与执行边界见[脚本图设计](../../../executors/script-graphs.md)。

## 范围与设计

- 当前图编辑会话提供 Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做，以及带操作名称提示的工具栏按钮。文本、数字输入与输入法组合优先保留原生编辑行为。
- 添加步骤完成后同时选中并聚焦新节点，适用于右键菜单、工具栏和双击空白处。菜单移除后键盘焦点仍属于图编辑器，可直接撤销、删除或移动新节点，无需再点击画布。程序化聚焦不自动滚动，边缘新增和历史恢复均保持画布滚动位置与视图变换。
- 历史覆盖节点、连线、布局、全部节点属性、参数增删和图并行数。删除节点与关联边为一个操作，恢复原 ID、配置及数组顺序。选择状态随操作恢复，但选择、平移、缩放、全屏和属性展开不独立记历史；命令顶层字段不加入图历史。
- 使用独立的内存快照历史模块。操作开始记录修改前草稿，结束记录修改后草稿；相同数据不入栈。拖动按下至松开、方向键一次按住至松键、同一属性的一次输入会话分别合并为一步。取消手势恢复修改前状态，保留 redo；有效新编辑才清除 redo 分支。
- 快照接受尚未连通或尚未填写完成的草稿，不经保存校验。恢复后强制同步属性面板、并行数和选中对象；保持视图。步骤名称等用户文本原样保留，操作标签延迟本地化。
- 最多保留 100 步，并以快照的估算数据量实施 16 MiB 历史预算；当前草稿和正在编辑的操作不属于已提交历史预算。超过预算移除最早记录；单次操作超过预算则清空历史并提示容量限制，继续允许编辑与保存。估算值不是浏览器堆内存保证。
- 保存读取只生成、校验提交副本；坐标整体平移只发生在副本。保存成功更新修订与保存基线，不重新加载同一图、不清历史、不改变画面。撤销不自动保存。保存失败或冲突保留草稿和历史。脏状态比较整个表单与保存基线，图使用相同的序列化规则。
- 保存基线同时持有本次提交内容和服务端确认内容；对应字段恢复到任一形式均视为已保存，可独立恢复规范化前后的名称、路径和别名。只用于比较，不覆盖历史原文，也不在前端复制服务端的路径规则；其他真实修改仍为未保存。Web 新增模块必须进入内嵌资源清单，并用服务端模块依赖闭包测试验证。
- 切换命令、主动重载、关闭重开按现有放弃修改确认后清空历史；语言、全屏、运行状态刷新不清空。运行中禁用 undo/redo，结束后可继续使用。保存/文件选择临时锁与运行锁区分；文件选择只允许当前会话、当前请求、仍存在且可编辑的目标接收回填。

## 实施顺序与职责

先同步本计划、Web requirements/design 和脚本图说明，再实现与验证。

- `web/graph-history.mjs`：快照、操作事务、容量裁剪、undo/redo，无 DOM 或持久化依赖。
- `web/graph-editor.mjs`：统一修改入口、快捷键、历史按钮、恢复、保存副本和生命周期。
- `web/graph-canvas.mjs`：拖动/方向键操作边界、取消恢复、原地改名结束与焦点。
- `web/graph-inspector.mjs`：属性输入会话、离散参数操作、历史恢复后的强制回填。
- `web/local-commands.mjs`：保存基线、表单脏状态、保存后保留编辑器、异步文件选择有效性。
- 词表源与生成资源增加中英文文案；不改变后端 schema、保存接口、命令执行和运行日志格式。

## 验收与验证

- 删除步骤后撤销完整恢复节点及关联边，重做重复删除；添加重做复用 ID；非法或无变化操作不污染历史。
- 真实浏览器中右键空白处选择添加步骤，随后不点击其他位置直接按 Ctrl+Z，应删除新节点；Ctrl+Y 恢复，节点 ID 和选择保持正确。验证必须发送真实键盘事件，不能直接向编辑器容器分发事件代替焦点检查。
- 在画布右下边缘通过菜单和双击添加，及撤销后重做恢复边缘节点，检查 scrollLeft、scrollTop 和视图变换保持不变，防止聚焦引入坐标换算未包含的隐式滚动。
- 拖动、方向键连发、属性连续输入各只占一步；取消、锁定、切换图不留下半次拖动；原生文字撤销与图撤销互不抢占，IME 不触发图操作。
- 属性、参数顺序、并行数、无效草稿可往返恢复；选中状态、按钮状态和中英文提示同步。
- 保存前后历史连续；撤销回保存状态清除脏标记，图外字段仍独立参与判断；负坐标保存不移动草稿或视图，失败/冲突不改变历史。
- 关闭/切换/刷新重置历史，锁定与解锁保留历史；过期文件选择不写入新会话或运行中的图。
- 历史 100 步与容量预算、极大单次修改、redo 分支裁剪均有自动测试。

自动验证入口为 `node --test tests/graph-history.test.mjs tests/graph-editor.test.mjs tests/script-graphs.test.mjs tests/local-command-management.test.mjs`，之后运行全部前端测试、`pwsh -NoProfile -File scripts/check-i18n.ps1` 和文档链接检查。实际浏览器检查焦点、原生文字撤销、中文输入法、按钮与保存后的交互；自动 DOM fixture 不替代这些检查。验证日志保存在构建产物目录的独立审计子目录，不进入长期文档。

内嵌 Web 模块使用 `go test ./internal/app -run '^TestWebModulesUseExecutableMIMEWithNoSniff$' -count=1` 验证：从实际 `index.html` 递归遍历模块依赖，检查所有文件进入可执行程序、GET/HEAD 返回正确 JavaScript MIME 及 nosniff。源码目录的浏览器测试不替代打包资源检查。

实际浏览器自动检查使用[浏览器验证入口](../../../../tests/graph-history-browser.mjs)，加载真实命令管理 HTML/CSS/模块，以内存 API 提供示例图，不连接已安装节点。使用运行依赖锁中已有的 `playwright-core`，不额外添加产品依赖：设置 `ASTERHAND_PLAYWRIGHT_MODULE` 为该包 `index.mjs` 的绝对路径，`ASTERHAND_BROWSER_EXECUTABLE` 为本机 Edge 可执行文件，`ASTERHAND_GRAPH_HISTORY_OUTPUT` 为本次独立验证目录，再运行 `node tests/graph-history-browser.mjs`。验证 Delete 后焦点、三个图快捷键、原生文字撤销、按钮提交输入、保存基线与失败保留，输出浏览器版本、检查项和截图。合成的 composition 事件只验证事件隔离；实体中文输入法切换后的节点名称设置与重命名已通过本机人工验收。

## 规模评估

历史算法单独成模块；修改的手写文件均低于 1000 行，词表生成资源另计。`graphEditor`、`graphCanvas`、`localCommands` 工厂闭包分别约 268、274、207 行：分别持有同一编辑会话、画布手势/视图和命令表单会话，内部操作函数仍短小；将这些闭包机械拆开会增加对可变状态、DOM 引用和生命周期的跨模块传递。快照与容量算法已独立，画布和属性面板只提交编辑意图。沿用现有工厂职责，不增加框架、主控类或通用命令系统；后续新增其他编辑工具时再按具体职责评估。
