# 本地快捷命令

- 状态：实现、工程验证和本机用户验收通过；跨环境专项边界见[验证说明](validation.md)。
- 目标：在快捷输入中通过 `/` 搜索并启动本机预注册脚本，无需模型配置。
- 关联：R04、R11、WEB-CMD-01—08、EXEC-CMD-01—05。
- 权威设计：[本地命令设计](../../../executors/local-commands.md)、[Web 需求](../../../web/requirements.md)、[执行器需求](../../../executors/requirements.md)。

## 范围和约定

Windows 首版支持 `.bat`、`.cmd`、Windows PowerShell 5.1 `.ps1`。Web 管理英文主名、多个 Unicode 别名、描述、绝对脚本路径、固定参数、工作目录和后台/终端模式。工作目录留空时随脚本所在目录解析。完整启动配置相同的注册合并名称并保留原描述，列表只出现一条。

脚本路径支持 Browse 调用 Windows 文件选择窗口，在当前屏幕工作区居中显示并回填绝对路径，取消保留原值。正常启动无额外提示；错误在对应命令行右侧持续显示最近一次异常，后续同命令启动成功清除，保留缺失错误的配置入口。

`/` 开头的单行输入进入命令模式；普通文本发送按钮提供显式聊天通道。命令模式支持高亮、方向键、左键单击、回车、IME 保护、自适应滚动、缺失标红及打开配置。Esc 先关闭列表，再隐藏窗口。启动后保留搜索和选中项，以便再次触发。

搜索按完全、前缀、包含、有序子序列匹配排序，忽略英文大小写；别名同样参与。首版不做拼音、纠错、语义搜索、动态参数、脚本上传、模型调用命令、远程执行、运行结果托管和自动重试。

## 实施步骤

1. 独立注册库和窄命令协议：验证、去重、持久化、修订冲突与启动回执。
2. Windows 非提权独立启动；固定 shell、参数传递、工作目录、环境和生命周期。
3. 继承本机 Web 认证的管理 API 和设置页面；原生桥仅传命令 ID/修订，不接受脚本路径。
4. 快捷输入命令列表、搜索、键盘/鼠标及窗口高度整合。
5. Go/Node 回归、Windows 实际脚本启动、受控页面/原生验证、文档链接检查。

## 验收

- 注册、修改、删除、搜索与重启保存；重复配置合并，跨命令名称冲突拒绝，删除注册保留脚本。
- Browse 的屏幕工作区居中、选择、取消、中文/空格路径、类型过滤、重复点击和请求取消；成功回填后仍由用户保存注册。
- 成功启动无提示；行内错误跨过滤/刷新/隐藏保留，新错误覆盖旧错误，成功清除，迟到回执不覆盖较新状态，错误文本可定位配置。
- 无模型配置可以启动；连续确认启动多个进程，慢脚本不阻塞聊天/输入；Asterhand 退出后脚本继续。
- 中文/空格路径、参数、工作目录、后台/终端模式；缺失、不可访问、配置变化及启动错误分别反馈。
- 列表多寡、过滤排序、别名展示、选中项滚动、IME 和 Esc；打开/过滤扩高期间无临时滚动条闪现，输入框与焦点下划线不因旧视口短暂上跳，确认限高后保留正常滚动；不把命令发送给模型。
- 本机认证/Origin/CSRF、IPC 来源/字段、旧版本、重复投递和未知回执边界。

## 规模和验证边界

按注册、启动适配、桥接、列表、管理页面分文件新增，现有入口只接线；不拆分已有文件。交付前检查新增和修改文件的物理行数。Windows 实测只证明本机受控环境；实体 IME、多屏/DPI、企业组策略和其他权限环境单独验收。

所有变更文件低于 1000 行，无需文件拆分。函数规模例外：`commandPanel` 与 Web `localCommands` 是列表及表单生命周期工厂，内部请求、渲染、事件和释放处理各自独立，闭包状态只属于一个面板；并发启动结果已分离到独立模型，继续拆散闭包会扩大接口。`inputEditor`、`chatPanel` 为既有编辑器/聊天工厂，保留已有闭包和草稿所有权；CLI `run` 为既有命令分发与节点配置入口，文件选择在节点初始化前短路，不引入通用执行分发。未来增加独立职责时重新评估。

批处理参数的字面双引号被明确拒绝，PowerShell 支持；批处理读取尾部反斜杠保持原值。该平台边界、注册容量和参数长度限制写入[本地命令设计](../../../executors/local-commands.md)。独立进程与能力边界见[架构决策](../../../executors/adr/002-local-command-launch-boundary.md)。

工程检查覆盖 Go 回归/静态检查/构建、前端回归、真实 Windows 脚本、真实 WebView2 列表及 Web 管理流程。本机使用体验已通过用户验收。真实 WebView2 中的输入法事件为合成事件；实体输入法、多屏/DPI、企业策略及其他权限环境仍按专项单独验证。

具体命令及支持边界见[验证说明](validation.md)。
