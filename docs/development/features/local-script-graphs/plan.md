# 本地脚本图

## 范围与依据

状态：实现、工程验证、独立审计修复复审和本机用户验收均已完成。用户通过本地快捷命令启动单脚本或静态脚本 DAG；图内支持串行、并行和多前置汇合。关联 R04、R11、EXEC-GRAPH-01—08、WEB-GRAPH-01—03。

权威行为见[脚本图设计](../../../executors/script-graphs.md)、[执行器需求](../../../executors/requirements.md)、[Web 需求](../../../web/requirements.md)及[架构决定](../../../executors/adr/005-local-script-graphs.md)。保留[托管命令](../../../executors/managed-local-commands.md)的普通用户执行、生命周期和日志完整性要求。

首版只在本机手动触发，不增加模型/远端/HTTP 启动入口，不提供循环、条件分支、嵌套图、自动重试、重启续跑、业务回滚或常驻服务就绪判断。脚本图必须托管；现有单脚本两种执行方式保持兼容。

## 设计与实现步骤

1. 升级注册格式，增加命令内容类型、图节点/连线和图并发上限；旧注册迁移为单脚本。后端校验静态 DAG，保存时允许脚本暂缺，启动前检查文件和工作目录。
2. 增加整图运行和节点执行身份、结果及配置快照。调度器归节点主进程所有，复用平台 ExecutionBackend；各节点的失败策略与实际结果分离。
3. 图内并发可配置为 1—16（默认 4），本机图节点总执行名额为 8；等待名额不占节点超时，计入整图超时。无依赖的节点可并发，同一命令仍单实例。
4. 任一节点失败立即禁止新节点启动，强制停止活跃节点，确认进程范围结束及日志保存后结束整图；停止/失败/超时统一仲裁，先确认的原因保留。重启核对所有已公布的节点执行身份，不重跑。
5. 日志持久化增加节点来源和独立解码上下文，保留旧日志读取。日志窗口提供节点状态、筛选和双栏显示，大日志仍按页补读。
6. Web 命令表单提供可编辑图、节点属性和连线操作；复用已有脚本选择器，支持从单脚本命令复制配置，保留实时国际化与运行期编辑保护。
7. 完成工程验证、独立 quality-audit 审计及范围内修复复审，并通过本机用户体验验收。

## 验收条件

- 串行链、菱形汇合及独立分支按依赖执行；同一节点一次运行中最多启动一次。
- 环、重复/无效边、不连通节点、错误开始/结束结构和容量越界在后端拒绝，界面能定位图或节点错误。
- 失败与启动交错、超时、人工停止和节点退出不漏启动，不遗留受管进程；未知清理继续占用，原始失败和被取消节点可区分。
- 保存、编辑、删除、修订冲突和旧配置/旧日志兼容；图节点不会合并进命令注册列表或覆盖其他节点日志。
- stdout/stderr、分块中文、无换行输出、分页、窗口重开、节点切换和双栏显示不串流；磁盘故障仍中止图并说明不完整。
- 状态/日志协议有界，最大图和高输出量不越过 IPC 限制；双语双主题保留未保存表单和选择状态。
- 旧单脚本托管/非托管、快捷搜索、停止与日志窗口行为通过相关回归。

## 验证

复现命令和验证边界见[验证说明](validation.md)。以 Go 可控执行后端覆盖依赖/事件竞争和恢复，用 Windows 真实脚本覆盖进程及输出；前端行为测试覆盖图编辑和日志筛选；构建、国际化与文档链接检查覆盖交付文件。生成物位于当前构建配置的输出目录，原始日志不作为长期文档链接。

## 规模评估

图模型、调度、节点执行、图编辑器和日志扩展按职责放入独立模块，现有单脚本路径保留。翻译 JSON 和生成词表属于数据/生成内容，不按业务代码拆分；词条仍以统一词表为权威。若业务文件新增后超过工程软限制，先评估并按工程规范处理。

当前手写业务文件均低于 1000 行。`graphEditor` 为 144 行，`localCommands` 闭包工厂为 210 行：两者分别保存一个编辑器/表单实例的 DOM 引用、草稿与生命周期，内部已按绘制、选择、校验、持久化和本地化划分短函数；移到外部会增加共享状态参数或可变对象的暴露，暂保持实例闭包。如果增加独立执行或图复用职责，再按新职责提取模块。

`runStore.read` 为 118 行，负责一页日志的顺序读取、帧完整性、解码上下文和容量/游标提交。它们共同决定这一页能否被安全接受，拆散会增加“上下文已加入但帧未加入”的状态交错；底层解码和前页定位已独立，保留顺序流程并由最大图分页回归验证。后续新增日志格式或独立索引时重新评估。
