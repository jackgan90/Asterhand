# 托管本地命令、独立日志窗口与执行控制

## 基本信息

- 状态：实现、工程验证、独立审计修复复审及用户验收已完成；真实环境专项和平台支持边界见[验证说明](validation.md)。
- 目标：本机手动启动脚本时可选择托管，实时查看 stdout/stderr，保存最近结果和日志，支持强制中断及可选执行超时。
- 关联：R04、R11、EXEC-CMD-01—05 的兼容性；新增 EXEC-CMD-06—15、WEB-CMD-09—14。
- 权威契约：[执行器需求](../../../executors/requirements.md)、[托管命令设计](../../../executors/managed-local-commands.md)、[Web 需求](../../../web/requirements.md)、[Web 设计](../../../web/design.md)、[安装与环境设计](../../../installation/design.md)。
- 架构决定：[托管本地命令的生命周期和日志权威](../../../executors/adr/003-managed-local-command-lifecycle.md)。
- 现有行为与回归基线：[非托管命令设计](../../../executors/local-commands.md)、[本地快捷命令验证](../local-quick-commands/validation.md)。

## 范围

1. 注册托管/非托管类型，旧数据和新建默认非托管；非托管行为保持兼容。
2. 托管按命令 ID 单实例，后台无交互启动，跟踪进程及其受管子进程；不同命令可并发。
3. 捕获 stdout/stderr，保存最近一次完整日志和执行元数据；终态跨窗口、宿主重建及节点重启保留。
4. Asterhand 独立日志窗口，复用项目主题和国际化，提供多命令查看、增量跟随、历史补读及停止入口。
5. 用户强制停止记为执行中断；退出助手终止所有托管执行并记中断。关闭 UI 窗口不停止脚本。
6. 注册可选超时，默认不设置；超时强制停止并记执行出错，详情说明 timeout，保留日志。
7. 注册列表与快捷列表显示类型、正在执行/正在停止以及持久的执行完毕/执行出错/执行中断。
8. 运行中禁止编辑/删除/切换类型；托管改非托管在控件旁提示，保存时删除最近结果和日志，无新增确认弹框。

非目标：交互终端、暂停/恢复、跨节点执行、模型调用、执行队列、自动重试、重启续跑、助手退出后的常驻脚本代理、多份执行历史、业务副作用回滚、通用工作流和具体 coding harness。

## 平台抽象与接入门槛

首个实现只交付 Windows；公共核心和 UI 业务协议按跨平台契约实施。详细接口见[平台边界与最小接口](../../../executors/managed-local-commands.md#平台边界与最小接口)。

| 边界 | 本轮应落到设计及后续 Windows 实现中的约束 |
|---|---|
| 注册策略 | 把现有 Windows 扩展名、路径等价/ADS 和批处理转义规则移到 CommandPolicy；命令名、ID、类型/超时及容量校验共用 |
| 执行后端 | 核心使用不透明 Execution；启动/双流/整次停止/完成确认/恢复证据归 ExecutionBackend，Job/令牌和未来 POSIX 机制不进入公共协议 |
| 计时 | ExecutionClock 提供含睡眠的经过时长与可取消唤醒，公共预算不绑定 QueryInterruptTime 或某平台默认定时器 |
| 窗口与页面桥 | 公共 LogWindowHost、HTML/CSS/状态与日志视图、send/subscribe 协议；WebView2/STA/HWND/任务栏只在 Windows adapter |
| 传输与存储 | 版本化有界消息独立于继承句柄/文件描述符；日志格式共用，必要的原子文件/权限差异留在窄函数 |
| 装配与分发 | 按目标装配执行、窗口和安装组件，复用既有发布目标机制；公共代码不写死 .exe、Windows shell 或 WebView2 依赖 |

执行结果能表示正常退出码、信号/异常终止和未知证据；停止原因仍由公共状态机决定。能力描述与当前环境可用性分开，UI 按能力呈现；缺少受管范围停止、宿主死亡清理等必需保证时拒绝托管启动，不回退为非托管或只杀根进程。日志窗口不可用独立降级，不影响已接纳执行。

本功能首个实现阶段仅为 macOS/Linux 保留明确不支持的适配入口，并使用契约替身验证边界；不提前引入新 UI 引擎、systemd/cgroup、常驻监督服务或新脚本类型。未来接入应集中在上述适配器、构建/安装和原生测试；若出现能力缺口，先明确设计取舍，不能靠伪造接口成功掩盖。进程组不预设与 Windows Job 等价，注册文件中的脚本路径仍由所属节点的平台策略解释。

只调整本功能新增依赖及触及的注册校验，不借此全面重构快捷输入、任务执行器或全项目平台层。公共核心的依赖方向和平台替身测试从 Windows 首个实现就建立，避免等第二个平台接入时才拆分。

## 中断和超时带来的设计增量

| 主题 | 计划约定 |
|---|---|
| 状态 | 增加持久 interrupted 与瞬态 stopping；timeout 是 failed 的原因，不单列第四种结束结果 |
| 统一控制 | 用户中断、超时、节点退出和日志故障共用运行控制器和平台进程树终止能力 |
| 请求身份 | 停止和日志读取绑定 command ID/run ID，重复停止幂等，迟到请求不得作用于新执行 |
| 结果竞争 | 逐 run 串行仲裁，终态只提交一次；已完成不追改，已接纳的停止原因不被强杀退出码覆盖 |
| 占用释放 | 进程树退出确认、管道排空和终态提交后再允许重启；停止未确认保留占用 |
| 超时预算 | 开始执行起计算整次总时长，配置快照固定，不因输出或 UI 关闭重置；收尾预算独立 |
| 系统时钟 | 计划计入睡眠/休眠，恢复后复核，不唤醒系统；计时不受手动修改系统时间影响 |
| 日志完整性 | 强制停止继续排空已经写入管道的内容；未输出的用户态缓冲和已发生副作用不承诺恢复 |
| 退出接线 | 与现有 RequestStop/Close 的准入、忙状态和关闭次序整合；IPC 请求取消不取消已接纳执行 |
| 故障恢复 | 保存停止意图，重启保留已知原因；无最终证据显示中断及结果未确认，不自动重试 |

这些规则及错误处理以[托管命令设计](../../../executors/managed-local-commands.md)为单一契约来源。

## 实施步骤

1. **配置与迁移**：先定义消费者所需的窄平台接口，增加类型/超时，明确整数秒边界，schema 升级、去重、旧修订拒绝及托管编辑合并保护；现有 Windows 注册规则通过 CommandPolicy 保持兼容，前端读取能力描述。
2. **运行管理与存储**：新增平台无关的执行身份、每命令准入、状态机、停止原因、日志写入/补读、替换/删除/恢复，注入 ExecutionBackend/ExecutionClock。先覆盖确定性竞争、异平台策略替身与故障用例。
3. **Windows 进程适配**：创建时绑定独立 Job，普通用户令牌、继承句柄白名单、双流并发捕获、退出码、强制停止及子进程收尾；运行真实 bat/cmd/ps1 验证。
4. **应用与协议接入**：接入节点退出与忙状态，增加 stop/status/log/open-log 能力，验证 HTTP 认证/CSRF 和窄 IPC。保持没有 HTTP 启动、远端和模型命令执行路由。
5. **独立日志窗口**：定义平台无关窗口、页面桥与传输契约，首个非提权 Windows/WebView2 宿主按需管理多个顶层窗口，接入资源、主题、国际化、任务栏、大小/DPI、分块日志和停止控件；UI 故障独立于执行。
6. **列表与注册体验**：增加类型/结果、超时配置和停止入口；防止点击停止或日志时触发执行；类型切换的就地删除提示、运行中编辑保护与日志失效。
7. **打包和交付检查**：按平台目标接入日志宿主完整性/版本校验，首版完成 Windows Fast/Full 安装、内嵌资源及国际化守卫；检查公共层无具体 OS 依赖，运行相关回归并完成独立窗口实际验收。

Windows 日志 UI 复用已校验的宿主可执行文件，以 --log-host 独立进程运行；窗口由独立管理器持有，共享底层 WebView2/COM 与资源设施。现有构建、图标、manifest、Fast/Full 应用组件自动包含该模式。执行器不依赖快捷输入包。

## 验收矩阵

以下是完整验收标准，自动验证入口、可复现步骤和未覆盖的真实环境边界见[验证说明](validation.md)。

| ID | 场景与预期 |
|---|---|
| MC-01 | schema 1 注册迁移为非托管；后台/终端、重复并发、节点退出后继续运行及参数规则回归不变 |
| MC-02 | 同一命令通过主名、别名、多入口并发启动只产生一次执行；不同命令可并发；拒绝请求不清日志 |
| MC-03 | 运行期逐步产生 stdout/stderr，无换行、超长行、大量输出和跨块中文均可查看；未打开窗口也完整捕获 |
| MC-04 | 退出码 0、非零、启动失败正确显示；stderr 有内容且退出码 0 仍成功；PowerShell 和外部程序结果传递契约明确 |
| MC-05 | 列表和日志窗口停止同一执行均有效；停止根进程及后代，排空输出后记中断，重开可读中断前日志，再执行恢复可用 |
| MC-06 | 无超时长时间运行；设定超时后即使持续输出也超时失败；静默但尚未到期不误判，日志可读；新运行重新计时 |
| MC-07 | 正常结束/中断/超时/节点退出分别交错，终态只提交一次；重复停止幂等，旧 run 停止和旧 timer 不影响新执行 |
| MC-08 | 停止请求已接纳但进程尚未退出时禁止重启；模拟终止失败、退出确认超时和日志收尾失败，不虚报已结束 |
| MC-09 | 超时输入的空值、单位转换、零/负数/小数秒/溢出校验；配置编辑不改变在途预算；正常退出后慢日志收尾不判执行超时 |
| MC-10 | 可控时钟覆盖时间跳变和睡眠恢复；真实睡眠/休眠后到期的活跃执行被停止，计时不受调整系统时间影响 |
| MC-11 | 关闭快捷输入、关闭/最小化日志窗口及日志宿主重建不取消脚本；窗口重开按游标补读，无重复或串 run |
| MC-12 | 节点正常退出/升级时阻止新执行、终止全部受管进程并保存中断；取消既有退出确认时所有入口仍可用 |
| MC-13 | 节点在启动、执行、停止意图落盘、终态提交等阶段崩溃，恢复不自动重跑、不误报成功；残留进程身份不确定时保持占用 |
| MC-14 | 运行期编辑/删除/类型切换均拒绝；取消未保存切换保留日志，保存非托管或删除命令清理日志，脚本不删除；失败恢复不复活旧日志 |
| MC-15 | 最新一次替换、执行配置快照、合并注册保留目标记录和危险编辑合并拒绝；旧窗口/旧游标不读取到新旧混合内容 |
| MC-16 | 日志容量大于 UI 缓存仍可完整查阅；写盘/读取故障、磁盘满、残缺尾记录和原子发布失败均显示准确边界，内存有界 |
| MC-17 | 普通用户/管理员节点下脚本非提权，节点私有环境和多余句柄不继承；HTTP/IPC 来源、CSRF、非法 ID/游标、旧宿主和权限拒绝正确 |
| MC-18 | 独立窗口主题/语言、任务栏、最大化/大小调整、多窗口去重、滚动跟随、DPI/多屏；日志按钮和停止按钮不误触启动 |
| MC-19 | 同时进行聊天、普通任务和托管命令，互相不占执行槽，停止某命令不影响其他工作；非托管无停止/日志能力 |
| MC-20 | 正式构建和快速本地安装均包含完整日志宿主/资源/身份校验，升级保留注册和最近日志；损坏/不同版本宿主只降级查看功能 |
| MC-21 | 同一公共状态机分别注入 Windows 风格和不同路径/执行语义的替身策略，支持大小写敏感路径与非批处理参数；实际 Windows 注册行为不变，不提前启用新脚本类型 |
| MC-22 | 后端返回正常退出、信号/异常终止、未知及停止未确认，结果分类和 run 互斥正确；等待超时不释放执行所有权，信号终止不伪造正常退出码 |
| MC-23 | 执行/窗口能力缺失分别准确拒绝或降级，前端不按 OS 名称绕过；缺少完整受管清理保证时不执行脚本，不回退非托管 |
| MC-24 | 公共核心、协议和日志视图不直接依赖 Windows 类型/具体 WebView；替身 bridge 运行同一日志/停止流程；Windows/macOS/Linux 编译边界成立，非 Windows 返回明确 unsupported |
| MC-25 | 平台时钟替身证明含睡眠语义和日历跳变隔离；存储替身覆盖不同文件删除/发布失败顺序，不把文件系统特性写入公共结果；未来适配须跑同套契约并补原生验收 |

公共核心契约在无桌面/无原生 API 的测试环境运行；设计审查与导入约束检查禁止平台类型进入公共模型及协议。非 Windows 构建检查和替身只证明边界可替换；macOS/Linux 的真实受管进程、监督机制、渲染器、权限、计时、存储及安装仍按后续平台交付验收，保持[支持矩阵](../../../testing/platforms.md)的当前边界。

本功能不依赖模型调用与双机；原有模型和双机产品验收边界保持独立。文档检查覆盖本地链接、范围一致性及变更差异；原始运行输出放忽略目录，长期文档只保留方法与支持边界。

## 规模与职责

运行控制、Windows 进程、日志存储、日志宿主和窗口视图按职责新增文件；现有注册、应用和列表入口仅做相关接线，避免把完整实现塞入单个控制器或聊天模块。

当前手写关键入口均低于 1000 行，无已识别的必需超限拆分。两个 `i18n-catalog.mjs` 是由源词表生成的资源，按生成代码例外管理，不手工拆分。实现时重新检查文件/函数物理行数及工厂闭包内聚性；达到工程规范触发条件时先评估并提出拆分方案，取得同意后实施。低层窗口复用仅覆盖 COM/资源/图标等明确职责，不借本功能扩展通用桌面框架。
