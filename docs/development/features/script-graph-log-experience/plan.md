# 脚本图编辑与日志查看体验

## 范围与依据

状态：实现、工程验证及本机用户验收完成。改进已交付的[本地脚本图](../local-script-graphs/plan.md)，覆盖 EXEC-GRAPH-09、WEB-GRAPH-04—07：结构节点隐藏脚本设置；统一日志选择入口；运行节点自动分屏与固定多选；独立节点历史翻页和状态颜色。

保持现有图调度、失败停止、单实例、日志持久格式和最近运行保留规则。Start/End 仍参与图和运行状态展示，不产生脚本日志，不进入日志节点选择列表。

## 设计

1. 选中 Start/End 或没有选中脚本节点时隐藏整个脚本属性区域；连线和图布局操作保持可用，脚本节点继续遵循运行锁。
2. 单个下拉面板提供“合并全部日志”“自动展开运行节点”和节点复选列表。自动选项互斥；勾选节点进入固定多选模式，切换自动选项清空多选，取消最后一个勾选显示选择提示。
3. 自动模式包括 starting/running/stopping/draining 的脚本节点，只在 finished 后移除；无活跃节点时显示空态。固定模式保留已完成及尚未执行的选中节点。状态列表、整图结果及失败原因独立保留。
4. 分屏按图节点顺序排列为响应式网格；每屏保留独立分页、解码器、滚动和跟随状态。按需读取被显示的节点，隐藏后释放视图缓存；切换语言/主题不重建已有分屏。新运行清理旧请求和缓存，默认回到合并视图。
5. 复用最近整图日志文件，读取请求增加可选节点 ID 与向前翻页方向。按节点返回有界页和该节点解码上下文；按文件偏移定位，单次最多扫描 1 MiB 或 4096 帧，跨无关输出的空页由前端分批继续查找。保留每页 96 KiB 和 IPC 限制；分屏读取并发受控，不随选中节点数无限增加。
6. 节点列表、选择项和分屏标题使用统一稳定状态映射；区分等待、就绪、启动、运行、停止、日志收尾、成功、失败、中断、未执行和未知状态。颜色配合文字，在两种主题下保持可读。

## 验收与验证

- Start/End 隐藏设置，脚本节点恢复设置，切换不丢失草稿且运行锁仍生效。
- 三种日志模式互斥；多选持续保留已完成节点，空选择和无活跃节点有明确提示。
- 自动分屏跟随节点状态增加和移除，停止/日志收尾不提前消失；失败原因在分屏消失后仍可查看。
- 并行节点历史可独立补读；一屏暂停或翻页不影响其他屏；稀疏节点、长日志、分块中文和旧日志兼容。
- 快速切换模式、换语言、重开窗口、重新运行时不串日志，不采纳已移除分屏的迟到响应。
- 每页、单次扫描、读取并发和分屏缓存有界，最大图和实际 IPC 编码回归通过。

使用 Go 存储/协议回归和前端行为测试验证，运行国际化与资源检查、全仓库文档链接检查；真实浏览器检查两种主题/语言的编辑和多屏布局。复现入口见[验证说明](validation.md)。

## 规模评估

节点日志读取作为独立存储查询模块；前端分别维护查看模式、单屏读取与渲染、窗口状态刷新。已有单脚本读取和图调度不承担视图选择职责。改动的手写代码文件均未超过 1000 行；两个 `i18n-catalog.mjs` 为词表生成文件，不按手写代码拆分。

`logPane` 为 102 行，包含单屏 DOM 创建、局部渲染和事件绑定；`logReader` 为 108 行，包含独立的查页、接收和请求函数，共享当前页、解码器与请求代次。内部操作函数均低于 100 行。保留这两个工厂的闭包结构，可使每屏状态与销毁操作保持在一起；为压缩外层行数而抽出函数会额外暴露可变状态。后续增加新的读取策略或工具栏职责时重新评估。

已有 `graphEditor` 增至 145 行，只新增属性区域显示判断，仍在实例闭包内维护同一份编辑状态；`runStore.read` 减至 111 行，保持单页帧校验、上下文和容量提交的顺序。两者继续沿用[原功能计划的规模评估](../local-script-graphs/plan.md#规模评估)，本次不引入额外职责。
