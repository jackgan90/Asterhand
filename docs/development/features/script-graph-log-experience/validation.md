# 脚本图日志体验验证

## 工程检查

使用项目依赖清单指定的 Go 和 Node.js。运行 `go test ./...`、`go vet ./...`、`node --test tests/*.test.mjs`、`pwsh -NoProfile -File scripts/check-i18n.ps1` 和 `node scripts/verify-frontend-assets.mjs`。需要启动 Windows 脚本进程的 Go 测试应在普通用户桌面环境执行。

节点读取专项需验证稀疏/交错输出、独立历史页、向前/向后翻页、尾页、分块解码、最大图响应预算、无效节点和旧运行拒绝。前端需验证模式互斥、节点固定多选、运行节点动态变化、独立跟随、迟到响应丢弃和国际化状态保留。

测试入口：

- [节点日志读取](../../../../internal/localcommands/node_logs_test.go)：早期节点被大量其他输出隔开的情况、扫描字节/帧数边界、中文解码上下文及实际 IPC 编码大小。
- [请求参数](../../../../internal/localcommands/wire/protocol_test.go)：节点筛选与向前读取参数只能用于相应日志操作。
- [日志读取器](../../../../tests/log-reader.test.mjs)：分页、单屏暂停、读取并发、隐藏/移除后的迟到响应，以及状态先完成但末尾日志尚未返回的时序。
- [工具栏稳定性](../log-toolbar-refresh-stability/plan.md)：已有日志自动补读时按钮文字、可用状态及焦点稳定，主动翻页替代在途自动读取，迟到响应丢弃，初次及主动加载继续防重复。
- [脚本图界面](../../../../tests/script-graphs.test.mjs)与[日志窗口刷新](../../../../tests/managed-command-ui.test.mjs)：属性隐藏、自动/手动模式、节点颜色、稳定的分屏顺序和独立状态刷新。

## 桌面检查

在图编辑器交替选择 Start、脚本、End，确认只有脚本节点显示脚本设置，草稿及连线操作正确。运行包含串行/并行步骤的脚本图，切换合并、自动和固定多选；让节点分别进入成功、失败、中断和未执行状态，核对状态文字、颜色及顶部失败原因。

选中一个已经完成的节点，检查其历史日志；翻阅该分屏时其他运行节点仍刷新。自动模式中停止和日志收尾阶段保留分屏，结束后移除；没有活跃节点时显示提示。多选清空时不自动切换其他模式。

运行持续输出及暂时没有输出的脚本，分别观察合并和节点日志：“回到最新”等分页按钮不随自动读取变暗、变亮；自动读取尚未返回时点击翻页仍能切换，旧响应不覆盖新页面。首次加载、主动翻页及编码切换期间继续防止重复操作。

中英双语和两种主题分别检查下拉面板、状态文字、分屏标题、窄窗口与多节点网格，确认语言切换保留选择、阅读位置和跟随状态。实体桌面用户验收和 DPI/多屏等专项分别记录，不以 DOM 测试代替。
