# 源码许可与发布

## 目标与范围

关联 R26、DEV-08/09。源码仓库为 [jackgan90/Asterhand](https://github.com/jackgan90/Asterhand)，默认分支 main；项目采用 [MIT License](../../../../LICENSE)。保留许可证、版权声明与第三方依赖许可。

## 发布契约

本地提交、远端推送与二进制 Release 分别授权。提交前核对暂存范围、差异格式、凭据误提交和依赖许可；不得从实现完成或用户验收推断推送许可。

程序发布物包含安装器、包、发布清单、完整性校验与第三方许可证。源码发布不代表任意平台的二进制支持，支持范围以 [平台矩阵](../../../testing/platforms.md) 为准。

## 验证方法

使用 Git 检查待提交路径、暂存差异及提交树；本地提交后检查工作区和分支状态。正式发布时核对 release manifest、包摘要和实际下载产物，具体步骤见 [依赖维护](../../../../packaging/upgrade.md)。

本功能不改变运行时行为或产品代码规模。
