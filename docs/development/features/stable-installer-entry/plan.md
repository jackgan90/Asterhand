# 固定安装入口与版本选择

## 范围与需求

仓库根目录 install.ps1 作为 Windows 固定安装入口，默认解析 GitHub Latest 稳定 Release，支持 Version 指定应用版本和 ReleaseTag 指定精确标签。关联 INST-01、INST-06、INST-15、INST-19；当前有效行为见 [安装需求](../../../installation/requirements.md) 与 [安装设计](../../../installation/design.md)。Linux/macOS 后续入口遵循相同契约，本次不实现其安装。

## 设计与边界

固定入口随源码维护，不包含应用版本默认值。Latest 只解析一次，随后下载同一标签的清单和 ZIP；依赖版本仍从包内固定清单读取。指定版本直接映射 v<version>；自定义标签从其清单取得应用版本。没有稳定版时明确失败，不自动改装预发布版。

本地包从相邻清单推导版本，不查询 Latest；显式版本、仓库或标签与清单冲突时拒绝。Release 可附带同一入口脚本，构建仅设置目标仓库，不绑定版本；安装该 Release 时显式传 ReleaseTag。

## 验收与验证

- 在 Windows PowerShell 5.1 验证默认 Latest、精确版本、预发布版本、自定义标签、本地清单版本推导与参数冲突。
- 模拟 GitHub 边界验证 Latest 解析后固定标签，拒绝无稳定版、网络错误、非法标签、错误清单版本或发布坐标。
- 使用真实公开测试包运行固定入口，验证下载校验、安装、配置未初始化及重复安装保留数据。
- 运行已有发布契约、系统依赖契约和安装路径回归；检查文档本地链接。

测试日志保存在运行者选择的输出目录。源码实现、公开固定 URL 生效、用户桌面验收、提交和推送分别报告。固定 URL 只有在相应源码推送后更新。
