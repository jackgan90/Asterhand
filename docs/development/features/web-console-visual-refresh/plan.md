# Web 管理页视觉升级

让 Web 管理页与快捷面板保持同一套视觉语言，并以普通用户能理解的文案替代协议和实现细节。功能、接口、保存语义与任务行为保持不变。

状态：实现、工程验证完成，用户验收通过。面板主题保存后页面实时切换、真实模型与双 Windows 设备上的表现仍按下文验证方式在实际安装中复核。

## 范围与依据

- 关联需求：[Web 需求](../../../web/requirements.md) WEB-01—06、WEB-09、WEB-11；行为范围沿用现有实现，不新增需求。
- 权威设计：[Web 设计](../../../web/design.md)的“视觉与文案”一节，及快捷输入、交付边界中的相应更新。
- 涉及领域：Web 管理页（`web/`）；网络状态提示文案（`internal/network/`）。
- 不涉及：快捷面板资源、API 路径与字段、配置格式、任务引擎、认证与 CSP。

## 设计

| 方面 | 决定 | 原因 |
|---|---|---|
| 视觉 | 复用快捷面板的星核/霜蓝颜色变量、品牌符号、光晕与网格；卡片和弹窗使用半透明玻璃面板 | 两个入口原本风格割裂；共用变量保证主题一致 |
| 主题来源 | 页面跟随快捷输入设置的面板主题，登录后读取并在保存后立即应用；浏览器本地缓存最近主题 | 用户只需设置一次；缓存减少打开时闪烁，读取失败不影响功能 |
| 信息量 | 技术信息收进折叠区，而非删除 | 普通用户界面更简洁，排障所需信息仍可查看 |
| 设置结构 | 常规 / 模型 / 快捷输入 / 网络与高级四页，CSS 切换，表单与保存按钮不变 | 原长滚动弹窗混合两类配置；分页不改变两个表单各自的事务 |
| 快捷键区 | 状态合并为一行；“重试生效”仅在需要时出现；手动选择按键折叠；主题改为预览卡片 | 录制是主要路径，减少同时出现的操作按钮 |
| 发送提示 | 空输入只禁用按钮，不再显示示例说明 | 占位文字已说明用途 |
| 后端文案 | 网络警告与 Tailscale 状态改为面向用户的短句，不再提及 TLS 身份、start.ps1、Tailnet 等术语 | 这些文字直接显示在页面上 |

规模：`web/style.css` 约 740 行，`web/index.html` 约 280 行，均低于文件软上限；新增函数均小于 100 行。既有外层工厂函数的行数评估沿用 [Web 维护性重构计划](../web-ui-maintainability/plan.md)的结论。

## 验收条件

1. 深色与浅色主题下，主页、设置四个分页、配对、本地命令与任务详情的视觉与快捷面板一致，文字对比可读。
2. 在快捷输入设置中切换主题并保存后，页面立即切换；刷新页面后保持。
3. 设置各页保存、模型测试、快捷键录制/检查/重试/恢复默认、配对、命令管理、任务提交/回答/取消/核对关闭的行为与改版前一致。
4. 必填项位于隐藏分页时，提交会切换到对应分页并显示浏览器校验提示。
5. 页面默认不显示节点 ID、数据目录、SHA-256、请求 ID 等技术信息；在折叠区或悬停提示中可以找到。
6. 窄屏下设置分页改为横向标签，主要区域可正常操作。

## 验证方式

在仓库根目录运行：

```powershell
$uiTests = Get-ChildItem -LiteralPath tests -Filter '*.test.mjs' -File
node --test $uiTests.FullName
go test ./web/... ./internal/app/... ./internal/network/...
```

文案调整同步更新了断言中文文案的用例（`tests/web-interactions.test.mjs`、`tests/web-state.test.mjs`、`tests/desktop-settings.test.mjs`），行为断言保持不变。

真实浏览器检查使用 [Web 浏览器 fixture](../../../../internal/app/web_browser_fixture_test.go)：设置 `ASTERHAND_WEB_FIXTURE_DIR` 为忽略目录下的新目录后运行 `go test ./internal/app/ -run TestWebBrowserFixture -count=1 -v`，用生成的 `session.json` 中的登录链接打开页面，粘贴其中的配对码，并提交任务以显示任务卡片。分别在两种主题下检查验收条件 1—6。截图保存在忽略目录，不进入长期文档。

FakeExecutor fixture 只证明页面渲染与交互；真实模型、双 Windows 设备与快捷面板主题联动仍需在实际安装中验收。
