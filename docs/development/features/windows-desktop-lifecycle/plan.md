# Windows 桌面启动与托盘生命周期

## 目标与范围

关联 C04、INST-08、INST-20—24、NODE-09 和 TASK-11。提供双击启动、节点内置系统托盘、明确退出和可选桌面快捷方式，统一脚本、桌面与登录后启动的行为。

权威文档：[安装需求](../../../installation/requirements.md)、[安装设计](../../../installation/design.md)、[节点需求](../../../node/requirements.md)、[节点设计](../../../node/design.md)、[任务需求](../../../tasks/requirements.md)、[任务设计](../../../tasks/design.md)。

## 设计

- 固定安装根目录的 GUI 启动器读取 installation.json，解析当前版本与数据目录；健康检查完成后退出。CLI 保留控制台与诊断接口，子节点以无控制台方式启动。
- Windows 节点进程拥有托盘和消息循环；菜单包含节点名称、助手状态、打开 Web、打开日志目录和退出。桌面快捷方式选择不影响托盘。
- 同数据目录启动串行化并复用已运行节点，含并发点击和启动尚未就绪的情况。安装器与启动器使用同一 Windows invariant 大小写映射及 UTF-8 哈希协议，Unicode 与目录别名通过跨进程锁互通测试验证。超时或锁占用不得擅自重启节点。
- 退出统一关闭任务接收、取消本机执行、关闭监听、等待持久化和进程清理，随后移除托盘。忙时提示一次；本机在途任务待核对，远端已接收任务继续，队列仍按既有期限处理。
- 处理 Explorer 重建、DPI 变化、锁屏与注销/关机；退出不停止 Tailscale，不删除节点身份与数据。系统托盘是否折叠由用户的 Windows 设置控制。
- 桌面使用当前用户 Known Folder 路径，支持重定向和 Unicode。安装提供 Auto/Create/Skip/Keep；首次非交互 Auto 跳过，升级按实际存在的本安装快捷方式保留，手动删除后不复活。登录后启动独立配置且不弹浏览器。
- 采用星核、托举轮廓和互联节点的应用图标，托盘使用同一标识的简化版本；生成透明、多尺寸 ICO 并嵌入可执行文件。

架构决策见 [桌面入口与节点内置托盘](../../../installation/adr/004-desktop-launcher-and-tray.md)。

## 规模与支持边界

职责按启动器、系统适配层、应用生命周期、安装和图标构建分别组织；不引入完整 GUI 框架或新常驻监督进程。Windows 当前用户交互会话为支持范围；未登录服务、其他平台托盘、自动任务重跑和跨节点任务迁移不在范围内。工程验证、两台 Windows 真实模型验收、用户验收和发布分别记录。

本功能涉及文件均在 1000 行以内。保留以下函数规模例外：

- [CLI run](../../../../cmd/asterhand/main.go) 为 107 行，较原先 133 行收窄，集中表达参数分派、服务锁和前台节点生命周期；继续拆分会隐藏清理顺序，保留顺序编排。
- [设置处理 settings](../../../../internal/app/api.go) 为 125 行，包含既有配置校验、互斥和持久事务，新接收屏障与原事务保持同一范围；拆开会增加锁与退出顺序的理解成本。
- [文件工具 fileTool](../../../../internal/tasks/tools.go) 为 104 行，本功能未修改，继续沿用 [任务可靠性计划](../task-reliability/plan.md) 的既有例外。

后续扩展入口职责或改变持久化边界时重新评估；本功能不进行无关文件拆分。
