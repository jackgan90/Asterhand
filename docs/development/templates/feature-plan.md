# Feature 计划模板

复制到 `docs/development/features/<feature-id>/plan.md`，填写实际内容；模板本身不是实施授权。

## 基本信息

- Feature ID / 名称：
- 目标与用户价值：
- 状态及实施授权范围：
- 关联 Rxx / Cxx / 领域需求 ID：
- 相关领域 requirements / design 链接：
- ADR（仅有新决策时）：

## 范围

- 本次实现：
- 明确非目标：
- 依赖和待验证假设：
- 验收用例及预期可见结果：

## 实施与文档同步

- 实施步骤：
- 必须更新的领域文档及实质内容：
- 契约、配置、安装、测试和用户说明变化：

## 规模与拆分评估

- 超限文件 / 函数及物理行数：
- 内聚性、拆分理由和安全性：
- 用户确认记录与获准范围（触发文件拆分时）：
- 例外理由或后续处理：

## 验证与交接

- 实际环境、版本、命令和结果：
- 证据链接：
- 未运行项和原因：
- 已实现 / 已验证 / 用户验收 / 提交 / 发布状态：
- 剩余问题与下一步：
