# 功能验证说明模板

此模板用于仓库中的长期验证说明，可保存为功能目录的 validation.md。原始执行结果另存忽略目录或对应版本发布物，不粘贴临时流水。

## 目标与契约

- 功能的完整名称及用户可观察行为。
- 关联需求、领域设计和测试源码的有效链接。

## 前置条件

- 支持的 OS / 架构、依赖版本来源、运行时与模型要求。
- 是否需要两台设备、网络、凭据或计费模型；凭据在专用表单配置。
- 示例参数的含义；目录由执行者选择，不填写开发者本机路径。

## 验证方法

| 行为 | 仓库测试入口或操作步骤 | 预期可观察结果 |
|---|---|---|
| 具体契约 | 可复现命令、测试名称或人工步骤链接 | 文件、状态、拒绝或恢复结果 |

## 支持边界

说明自动化覆盖、真实环境要求和未验证平台。缺少条件的实际运行记 skipped / blocked；未开始记 not_run。不要根据 fixture 通过推断真机通过。
