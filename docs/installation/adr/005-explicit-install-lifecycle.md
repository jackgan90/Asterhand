# ADR-005：显式停止与安装后启动

- 状态：accepted
- 日期：2026-10-25
- 补充：[安装配置分离](002-release-and-install-boundary.md) 与 [桌面入口](004-desktop-launcher-and-tray.md) 的默认安装行为；默认仍只安装。

## 决策

正式 install.ps1 提供 StopRunning 和 StartAfterInstall 两个显式选项。本地双击入口负责选择与当前源码指纹一致且校验通过的正式构建包，缺失时重新构建，再传参复用该安装器的校验、依赖、停止、激活及启动流程。首次使用标准目录；未显式指定 DataDir 的覆盖安装沿用已有安装记录，桌面图标默认保留实际状态。

停止发生在候选包及依赖检查成功后，且持有启动互斥量。安装器验证目标节点的程序归属、进程身份及本机健康身份，再调用现有认证停止 API，等待收尾完成；失败或未知状态保留现场并报错。安装成功且释放激活锁后，通过现有启动器启动节点。默认正式安装继续要求用户自行启动，配置和登录仍独立进行。

## 原因与影响

开发验收需要双击完成当前源码构建、覆盖和重启。将生命周期选项放在正式安装器中，使开发入口与用户安装共享同一实现，避免绕过包检查、运行时检查和数据保留。正常停止会取消本机在途工作，重启后的恢复沿用任务对账规则；不自动重跑任务，也不强制终止未知进程。
