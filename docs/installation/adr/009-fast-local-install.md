# ADR-009：本地目录候选与固定运行时复用

- 状态：accepted
- 日期：2026-10-29
- 替代范围：[ADR-005](005-explicit-install-lifecycle.md) 中本地入口必须经完整 ZIP 构建安装的要求；其安全停止和启动决策保留。

## 决策

本地入口默认 Fast：与正式构建共享应用组装，将应用目录候选交给独立安装器，运行时从安装目录内的不可变 generation 复用。应用版本用 junction 保持现有 runtime 相对布局，安装身份同时绑定应用与运行时 generation。依赖准备和修复只写新目录；正式安装器负责归属、实际路径分离、候选验证及既有停止/激活/启动流程。

Full 保留完整 ZIP 路径，用于分发包和安装验收。源码输入按内容完整核对，启动后验证实际节点的源码摘要。快速模式对已完成的运行时使用明确定义的关键文件检查；任意传递依赖损坏由重新按锁准备的修复流程处理。

## 原因与影响

频繁开发验收主要改变应用代码，完整运行时的复制、压缩、摘要和解压重复处理大量不变文件。分开应用产物和运行时，可以在保留内容身份、宿主配套与安全激活的同时消除热路径搬运。

安装器仍为兼容 PS5.1 的单文件，在线入口不依赖仓库工具。开发 helper 管缓存与构建，不接管用户数据生命周期。新增根目录初始化入口在写缓存之前验证归属；本地源码 guard 在锁内、停止之前执行。运行时换代产生新安装版本，旧版本不改链接。首次依赖准备和 Full 仍有完整 I/O 成本，通过阶段日志与心跳展示。

不自动清理旧版本/generation，不扩大为通用安装框架；清理链接必须避免遍历目标。完整契约与验收见[快速本地安装计划](../../development/features/fast-local-install/plan.md)。
