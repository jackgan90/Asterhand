# 安装与环境需求

范围：Windows 完整安装与升级，验证方法见 [数据与配置保留](../development/features/task-reliability/validation.md) 和 [安装路径解析](../development/features/installer-path-resolution/plan.md)。关联 C04、C05、C09。

| ID | 要求 |
|---|---|
| INST-01 | Windows 新节点通过版本化 install.ps1 引导，无需手动逐个下载依赖或编译 |
| INST-02 | 检测 OS、架构、环境和已有组件；复用兼容依赖，补齐缺失项 |
| INST-03 | 完整节点默认含 OpenClaw + DeepSeek 配置，不含 coding harness |
| INST-04 | 首次 Web 向导完成节点、凭据、授权目录、网络与配对准备 |
| INST-05 | 重复执行保留节点身份、配置与数据；中断可重试 |
| INST-06 | 发布锁定组件版本、来源和校验信息，安装不追随不受控 latest |
| INST-07 | 诊断区分已安装、待配置、检查失败和真正就绪 |
| INST-08 | 提供明确启动入口和可选登录后启动；系统修改说明范围 |
| INST-09 | 预留 Linux/macOS 平台构建与安装接口；当前正式发布目标只启用 Windows x64 |
| INST-10 | 节点运行环境与业务项目构建环境分开，不演变成通用包管理器 |
| INST-11 | 依赖版本由单一清单驱动构建、诊断和安装；更新先准备隔离候选，不原地修改运行中的 bundle |
| INST-12 | 升级验证包含锁文件、契约、真实模型与安装/数据保留回归；缺少任一项不得把升级标为通过 |
| INST-13 | 包描述明确组件、默认选择和全部运行时验证目标；公共准备/安装检查不写死模型或 agent 提供者，未知目标和未声明直接依赖拒绝 |
| INST-14 | Windows 安装参数中的相对路径以 PowerShell 当前 FileSystem 位置为基准；不受 .NET 进程工作目录影响，自动清单位于指定本地包旁 |
| INST-15 | 复制一行 PowerShell 命令即可下载并执行 install.ps1，支持默认稳定版及显式版本/标签，下载失败时停止；安装全部前置组件，包括所需 Microsoft VC++ x64 运行库和 Tailscale，激活前加载声明的原生模块检查系统依赖；默认安装结束后退出，登录、凭据与配对独立进行 |
| INST-16 | 统一发布命令自动准备锁定工具链、运行依赖、平台包、安装器、清单、许可证及校验文件，并上传至明确指定的 GitHub 仓库 |
| INST-17 | 先上传草稿并校验附件，再显式发布；失败保持草稿，重试拒绝覆盖不同内容和已公开版本 |
| INST-18 | 平台扩展通过声明式目标与独立 builder/installer 接口接入；未实现和未经原生验证的平台不得列为可安装发布目标 |
| INST-19 | 仓库维护固定安装入口，默认安装 GitHub Latest 稳定 Release，支持显式版本或标签；一次解析后锁定全部下载目标，本地包不查询 Latest，无稳定版时明确失败 |
| INST-20 | 提供带应用图标的 Windows 原生启动器，双击后无控制台闪现，确认节点健康并打开本机 Web；重复及并发启动复用同数据目录节点 |
| INST-21 | 安装可选择创建或跳过当前用户桌面快捷方式，升级默认保留已有选择；支持桌面重定向、Unicode 与含空格路径，快捷方式使用稳定入口 |
| INST-22 | Windows 交互会话中节点运行时提供托盘，与桌面图标选择无关；支持打开 Web、日志目录、状态和退出，Explorer 重建及 DPI 变化后恢复图标 |
| INST-23 | 启动失败提供具体错误与日志入口；健康超时和已有实例尚未就绪时不启动额外节点。关闭浏览器与锁屏不退出节点；注销与关机执行收尾 |
| INST-24 | 应用与托盘使用统一原创标识及透明多尺寸 ICO；登录后启动与桌面图标独立选择，登录自动启动不打开浏览器，安装默认不启动节点 |
| INST-25 | 提供 Windows 双击本地安装入口，复用指纹匹配且校验通过的正式构建包，源码变化或包缺失/损坏时重新构建，再复用正式安装器；首次安装使用标准目录，覆盖安装默认沿用原数据目录并保留身份、配置与凭据及实际桌面图标状态 |
| INST-26 | 正式安装器支持显式安全停止目标节点及安装后启动；包和依赖检查通过后才停止，核对进程与节点归属并等待正常退出，失败或未知状态终止激活；启动复用标准启动器 |
| INST-27 | Windows 快捷输入使用可诊断的 WebView2 Runtime；构建固定宿主依赖和许可证，安装按校验清单补齐缺失 Runtime，失败不停止旧节点；桌面设置和 profile 随本机数据目录保留，缺 Runtime 只降级输入面板 |

必须通过 [V01 干净环境安装](../testing/acceptance.md)；在开发机直接运行不替代安装验收。

提供 Windows x64 自带运行时的完整包、本地包/固定 Release 安装、摘要校验、独立数据目录、可选登录后启动、doctor/repair 和 Tailscale 引导。Linux 基础入口仍为实验交叉编译产物；干净设备安装按人工验收规程独立验证。
