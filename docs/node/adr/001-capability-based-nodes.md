# ADR-001：按能力部署和静态配对

- 状态：accepted（设计接受，尚未实现验证）
- 日期：2026-10-24
- 确认依据：产品需求与范围决策，详见所属领域 requirements/design。

## 决策

稳定节点身份与网络地址分离；任务服务、助手和执行能力可分别部署。首版静态配对并使用独立凭据，目标节点校验权限。

## 背景与后果

低配 Linux 无需 coding harness；用户与 peer 身份分离。配对协议、证书与人类授权证据必须分别验证，当前协议见 [节点设计](../design.md)。
