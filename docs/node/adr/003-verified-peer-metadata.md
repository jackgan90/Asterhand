# ADR-NODE-003：验证后的节点元数据同步

日期：2026-10-25。状态：accepted。

## 背景

配对时保存的名称和 endpoint 不随节点改名或地址修正变化。实机 A→B 可达而 B 保存 A 的旧 loopback 地址，刷新无法修复。更新显示名需要当前节点信息，更新地址还需要证明新地址仍属于同一身份。

## 决策

增加已有 peer 认证保护的 POST /v1/metadata，通知仅包含发送节点 ID 与当前 endpoint。接收方校验 ID 与认证 peer 相同，按原固定证书、node_id、出站凭据访问候选地址 /v1/info，核对返回身份、名称及公布地址；通过后原子更新原 peer 的 name/endpoint。不得接受通知携带的新证书、凭据、授权项目或撤销状态。远端来源不得公布 loopback 地址。

本机后台每 20 秒通知已配对节点，保存配置和成功配对时触发一次。监听配置尚未生效时暂不通知。普通节点信息探测也验证并更新元数据；公布地址与当前连接地址不同时额外回查一次。变更期间公布地址再次变化则保持旧记录并重试。

实机网络复核后，节点信息/回查总时限为 10 秒，通知外层为 15 秒；原 2 秒在线探测不足以覆盖已测到的 2.85 秒响应。保持有界失败和原信任校验，以慢连接 fixture 覆盖在线探测及元数据回查，不通过省略证书或身份检查缩短请求。

## 影响与限制

保留既有任务、origin、owner、配对凭据与授权；不重新提交任务。旧版本返回 404 时不影响原任务协议，双方升级后恢复同步。至少一个方向需要仍可通信；双方地址同时失效时，用户需重新配置或配对。不引入中心目录、广域扫描或证书自动轮换。

验证覆盖单向不可达修复、重启地址变化、改名、凭据/权限保留，以及错误 ID、替代证书、不可达地址和已撤销节点拒绝。
