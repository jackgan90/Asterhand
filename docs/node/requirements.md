# 节点需求

状态：已确认设计要求，实现契约见本领域 design.md，平台边界见测试文档。关联 R02、R05—R08、R17、R22、C04、C09。

| ID | 要求 |
|---|---|
| NODE-01 | 节点有稳定身份；地址、主机名和显示名变化不改变身份 |
| NODE-02 | 静态配对、独立 peer 凭据、可撤销授权，无固定业务中心 |
| NODE-03 | 支持任务服务、助手和执行能力分别部署；低配 Linux 无需 coding harness |
| NODE-04 | 展示在线性、能力状态及最后更新时间；在线不代表可执行某项任务 |
| NODE-05 | 目标节点最终校验 project_id、工具、操作和用户权限 |
| NODE-06 | 单用户的设备信任与人工审批身份分开，peer 提交权限不等于人工审批权限 |
| NODE-07 | 仅在授权且网络可达的节点间通信，失联后不自动转派 |
| NODE-08 | 配对后名称和地址可更新；地址变更须经原 peer 身份、固定证书和候选地址回查，不改变权限或复活撤销关系 |

## 首版边界

两台 Windows 是完整产品验收节点。Linux 可参与协议与故障测试，Mac 等待实际设备验证。手机先访问已部署节点的 Web。

网络使用现有 LAN / Tailnet；安装器检查实际可达性。初次配对、撤销和未授权访问纳入 [测试矩阵](../testing/matrix.md)。

已提供 Tailscale 安装/登录引导、证书固定配对与撤销、项目权限和离线缓存。Web 当前仅本机 loopback；手机远程接入尚未交付。NODE-03 的 Linux 基础包仅交叉编译，NODE-07 按实际网络拓扑独立验证，支持范围见 [平台矩阵](../testing/platforms.md)。
