# ADR-001：节点自治与薄任务层

- 状态：accepted（设计接受，尚未实现验证）
- 日期：2026-10-24
- 确认依据：本轮用户需求及后续明确收敛。

## 决策

完整节点独立运行助手和持久任务服务，任务由执行节点唯一负责。核心采用 Go + SQLite、版本化 HTTP + SSE，先使用已有 LAN / Tailnet。

## 背景与后果

避免 Linux 或单一 Gateway 成为所有业务的必经中心；运行时复用工具循环，自研边界限定在任务可靠性。
