# ADR-001：固定 owner 与持久对账

- 状态：accepted（设计接受，尚未实现验证）
- 日期：2026-10-24
- 确认依据：本轮用户需求及后续明确收敛。

## 决策

持久接收后才确认；原目标重试和稳定请求 ID 去重。启动前保存 attempt，重启先核对，不明状态保留现场；取消不等于已停止。

## 背景与后果

重启对账提前到 M1。终态、机器验证和用户验收分别记录，不承诺外部副作用 exactly-once。
