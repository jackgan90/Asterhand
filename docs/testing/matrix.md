# 自动化验收矩阵

本文定义故障与行为的预期矩阵，不表示整行场景均已验证。已实现的自动化入口见 [测试指南](../../tests/README.md)，真实设备步骤见 [人工验收](acceptance.md)。

| ID | 场景 | 必须观察到的结果 |
|---|---|---|
| A01 | 本机自然语言文件创建 | 真模型、真实工具与文件字节一致 |
| A02 | A 向 B 提交文件任务 | 持久接收且只启动一个 attempt |
| A03 | 同一请求重复提交 | 同一 job，无重复启动 |
| A04 | 相同 ID 不同内容 | 明确冲突，无新执行 |
| A05 | 接收事务成功后响应丢失 | 同目标重试获得原 job |
| A06 | 页面关闭 / A 服务退出 | 两种情况分别验证 B 独立执行 |
| A07 | A 重连与 SSE 补读 | 快照水位无漏缝，客户端去重 |
| A08 | B 失联 | 最后状态与时间，无自动转派 |
| A09 | 远程回答，含窄屏页面 | 正确 job / attempt / interaction |
| A10 | A 与 B 或手机并发回答 | 只接受一次有效改变 |
| A11 | 过期审批或实例替换 | 拒绝旧批准，不重放 |
| A12 | 取消 | 区分已登记与已停止，保留副作用 |
| A13 | B 服务重启 | 先对账，不盲目重启任务 |
| A14 | 启动成功但 native ID 未保存 | 关联已有执行或进入待核对 |
| A15 | 未授权 peer / project / artifact | 执行或读取前拒绝 |
| A16 | 工具成功、失败或验证失败 | 真实结果、失败原因与验收状态分离 |
| A17 | 同一工作区第二个写任务 | 排队或拒绝，未确认停止不释放占用 |
| A18 | 取消先到、提交后到 | 取消标记阻止迟到启动 |
| A19 | 排队过期、时间偏差 | 超过启动期限不执行，边界规则明确 |
| A20 | 回答保存后进程崩溃 | 对账原请求，不显示虚假已应用 |
| A21 | 取消与完成竞争、旧事件迟到 | 终态符合事实，旧 attempt 不覆盖新状态 |
| A22 | 数据库失败或磁盘满 | 无虚假接收确认，失败可诊断 |
| A23 | 游标缺口、慢客户端、大输出 | 明确缺口，资源有界，不拖垮任务 |
| A24 | Windows / Linux 路径边界 | 中文、空格、大小写、占用、链接逃逸正确处理 |
| A25 | peer 撤销、身份伪造 | 撤销后访问拒绝，peer 不冒充人类审批 |
| A26 | 清日志后重放旧提交 | 去重仍有效，无第二次执行 |
| A27 | 工具完成但结果尚未落盘 | 有证据核对或待核对，不以已有同内容文件冒充成功 |
| A28 | 新安装、中断重试、重复安装 | 配置与身份保留，依赖版本可复现 |
| A29 | key 无效、替换、删除、重启 | 准确能力状态，无明文泄漏 |
| A30 | 第三 Linux 节点退出 | 两 Windows 直接协作不受其退出影响 |
| A31 | 桌面、脚本与并发启动 | 无控制台启动，同数据目录一个节点，已有节点复用并恢复 Web 登录 |
| A32 | 桌面选择与升级 | Create/Skip/Keep/Auto 行为一致，手动删除图标不复活，Startup 独立，无关快捷方式保留 |
| A33 | 托盘与 Web 主动退出 | 忙时确认可取消，确认后关闭接收并有序收尾，释放端口和子进程，远端已接收任务继续 |
| A34 | 启动失败、超时与安装竞争 | 错误可诊断，早期活进程保留，无重复启动，运行中拒绝激活安装 |
| A35 | Windows 桌面与会话变化 | Explorer 重启恢复托盘，图标适应 DPI，锁屏继续，注销/关机调用统一收尾 |

## 执行要求

核心状态、传输和存储场景先在 FakeExecutor 下确定性运行；A01、A02、A06、A09、A16、A29 的关键产品路径还需真实 OpenClaw + DeepSeek 证据。

A30 仅在第三节点可用时运行，不阻止两机产品验收；Linux 自身支持程度仍需按 [平台矩阵](platforms.md) 记录。首版必要的审批拒绝 / 过期语义可通过受控 fixture 验证，真实 runtime 审批映射必须经真实接口验证后才公布能力。

A31—A34 由 Go、隔离 Windows 快捷方式和真实基础节点进程回归覆盖工程边界；A33 的跨机执行仍需真实 OpenClaw + DeepSeek。A35 的合成消息测试只证明消息处理路径，真实 Explorer、显示缩放和 Windows 会话行为按 [桌面验证说明](../development/features/windows-desktop-lifecycle/validation.md) 人工执行。

实际执行结果保存在忽略目录或版本发布物中；本表预期列不作为通过记录。
