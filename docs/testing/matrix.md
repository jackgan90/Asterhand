## 执行要求

核心状态、传输和存储场景先在 FakeExecutor 下确定性运行；A01、A02、A06、A09、A16、A29 的关键产品路径还需真实 OpenClaw + DeepSeek 证据。

A30 仅在第三节点可用时运行，不阻止两机产品验收；Linux 自身支持程度仍需按 [平台矩阵](platforms.md) 记录。首版必要的审批拒绝 / 过期语义可通过受控 fixture 验证，真实 runtime 审批映射必须在 M0 证明后才公布能力。

实际执行结果保存在对应 feature 验证报告，不能直接把本表预期列当作已通过记录。
