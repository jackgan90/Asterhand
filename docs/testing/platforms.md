## 依赖基线

| 项目 | 当前决定 | 精确版本 / 实测 |
|---|---|---|
| Go | 核心服务语言 | M0 固定 |
| SQLite | 节点本地状态；驱动优先避免 cgo | 驱动、版本、持久化策略待验证 |
| OpenClaw | 首版唯一助手运行时 | Windows 原生路径优先；版本与接口 M0 实测 |
| DeepSeek | 默认 provider | key 本地配置；模型与工具调用 M0 实测 |
| Web 工具链 / Playwright | 薄 Web / 关键交互自动化 | 版本和工具链待固定 |
| Coding harness | 首版不接入 | 不作为依赖或验证前置 |

早期讨论发现本机 CLI 可用不代表 Asterhand 已集成。产品平台报告只记实际参与本项目验证的依赖与版本。

## 发布要求

两 Windows 完整节点与真实模型闭环为首版必要证据。Linux 基础节点安装和协议测试按拟发布能力验收，低配机器不承担本地大模型或重编译任务。

Mac 只做将来目标，不以交叉编译通过声称运行支持。可用性变化时更新本表及测试报告，保留旧报告的历史环境信息。
