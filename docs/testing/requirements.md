# 测试需求

范围：单元测试、单机多节点、适配器契约、安装与真实产品验收。关联 C03、C09、TASK-01—TASK-10。

| ID | 要求 |
|---|---|
| TEST-01 | 单台 Windows、无模型 key 可运行核心状态与多节点故障回归 |
| TEST-02 | 真实网络、数据库和进程边界测试，不只测同进程 mock |
| TEST-03 | FakeExecutor、协议代理、可控时钟和明确检查点支持可复现故障 |
| TEST-04 | 真 OpenClaw + DeepSeek 验证不得被模拟成功替代 |
| TEST-05 | 两台 Windows 完成可见文件、问答和断线验收 |
| TEST-06 | 平台按能力和可用性分层，记录跳过原因与支持级别 |
| TEST-07 | 发布必测项缺失阻止发布，日常可跳过非必需外部环境 |
| TEST-08 | 干净环境安装、重装保留配置和已有环境兼容需要测试 |
| TEST-09 | 真实运行报告包含版本、环境、用例、结果和证据 |

首版不要求 coding harness 测试。新增适配器后才引入其协议 fixture 与真实兼容性门槛。

日常测试使用 Go testing、真实临时 SQLite/HTTP/TLS 和进程 fixture，不调用计费模型；真实 DeepSeek 由本机表单配置后独立验收。报告列出已运行子场景与未运行矩阵项，不将模拟双节点算作物理双 Windows 验收。
