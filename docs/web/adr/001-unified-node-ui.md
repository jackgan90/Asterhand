# ADR-001：每节点统一 Web 入口

- 状态：accepted（设计接受，尚未实现验证）
- 日期：2026-10-24
- 确认依据：本轮用户需求及后续明确收敛。

## 决策

聊天、节点选择、任务、交互和配置在同一 UI；清晰区分当前节点与执行节点。任务状态来自 owner，对话保留入口节点。

## 背景与后果

替代复用助手独立 UI 加单独任务页的早期建议；A 离线时可登录 B 处理任务，不引入全网会话同步。
