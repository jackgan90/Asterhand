# 本地命令完成通知设计

交付状态见[功能计划](../development/features/local-command-completion-notifications/plan.md)。命令注册和运行终态分别由[命令设计](../executors/local-commands.md)和[执行设计](../executors/managed-local-commands.md)负责。

公共通知服务接收不含脚本和日志正文的完成事实，统一管理等待、可见名额、暂停、失效和去重；平台展示器只绘制有序快照并回传真实显示及用户操作。Windows 首个实现复用独立非提权宿主，macOS/Linux 展示能力暂不可用，命令执行不受影响。

命令编辑表单中，执行超时单独占一行；“允许同时执行”和“执行结束后通知”在下一行使用等高卡片，标题顶部对齐。窄窗口下两个开关按顺序纵向排列。

提示在当前工作屏幕右下角排列，最多三张，工作区不足时减少数量。卡片包含命令名称、结果、耗时、开始时间、关闭和查看日志，背景和文字跟随已保存的节点主题/语言。高度按实际标题和可见错误信息测量，普通通知不为隐藏信息预留底部空白；宿主用实际高度保持卡片间距，首次显示前先按目标宽度与 DPI 完成测量。测量绑定通知身份和本次页面更新序号，旧回执不能改变复用窗口。初值为 240 ms 进入、180 ms 退出、200 ms 补位，可读时间默认 3 秒；鼠标悬停或主动键盘焦点暂停整组倒计时与自动补位。系统减少动态效果时取消位移，系统通知时长高于默认 5 秒时遵循较长的辅助功能设置。

等待队列最多 100 条详细信息，超过部分有界汇总；等待超过五分钟的详细信息也合并。汇总保留完成先后位置，后到条目不能使其饥饿。窗口关闭、热键关闭及浏览器退出不影响通知；锁屏和睡眠暂停展示，恢复后先处理过期信息。通知只存在于当前节点生命周期，重启不补播旧历史。

圆角同时覆盖页面背景与原生窗口：主题底色放在圆角卡片内，页面外层与 WebView2 默认背景保持透明；原生窗口继续按 DPI 使用圆角区域裁剪显示和鼠标命中范围。这样短卡片、长标题与错误提示增高后都不会露出矩形底色。网页截图只能检查内容像素，原生区域与桌面点击需另外验证。

Windows 为每个隐藏的通知窗口设置置顶样式。每次显示前检查原生窗口层级，如果置顶位缺失，先把隐藏窗口移至底部，再无激活置顶显示。动画只更新位置、尺寸和透明度。宿主在显示时以及发出进入回执前核对窗口可见性和置顶位。未能显示时走已有的宿主故障恢复流程，保留待展示的通知。窗口层级与无激活定位的 API 约定见微软的 [SetWindowPos 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)。

Windows 宿主在启动、会话变化和电源恢复时查询当前连接与锁定状态，查询失败时保持暂停；睡眠单独记录，只有会话可见且系统已经恢复才显示。退出中的卡片因其他卡片移除而补位时，继续原来的退出目标与剩余动画时间，隐藏回执返回后才释放名额。

查看日志必须绑定原始 command ID/run ID，支持保留期内的历史实例；删除或过期时明确反馈，不替换为最近运行。通知不主动抢焦点，不进入任务栏或系统通知中心，不承诺遵循 Windows 勿扰策略。操作和展示等价分别登记到[自动化覆盖清单](../automation/coverage.md)。

完整交互、排队竞争、宿主恢复和验收条件见功能计划；自绘方案的取舍见[桌面通知 ADR](../installation/adr/010-command-completion-notifications.md)。
