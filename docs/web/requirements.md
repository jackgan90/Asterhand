# Web 交互需求

状态：已确认首版形式，实现契约见本领域 design.md，平台边界见测试文档。关联 R03、R08、R09、U07、C02。

| ID | 要求 |
|---|---|
| WEB-01 | 每个节点提供同样的统一入口：聊天、节点、任务、配置 |
| WEB-02 | 明确区分当前连接节点与任务执行节点，默认执行本机 |
| WEB-03 | 选择器和自然语言都可指定目标，冲突时澄清 |
| WEB-04 | 卡片显示目标、状态、最后进度，详情支持事件、问答、审批、取消和产物 |
| WEB-05 | A 展示其本地任务及发起的远端任务；B 展示其执行任务，包括 A 发来的任务 |
| WEB-06 | 断线显示最后已知状态；重连补读；刷新不重复提交 |
| WEB-07 | A 下线时可直接登录 B 查看和处理任务，对话历史不自动同步 |
| WEB-08 | 手机使用同一响应式页面，不要求原生 App 或后台主动推送 |
| WEB-09 | 配置密钥使用专用表单，与聊天数据分离 |
| WEB-10 | 本机与远端任务按原提交时间统一排序；路由转执行和刷新保留卡片位置，禁用提交必须显示具体原因 |

实际用户验收必须在页面完成，不要求手动构造 HTTP 请求或进入运行时 CLI。

已实现 WEB-01—07/09 的本机与配对任务页面主路径。WEB-04 审批未开放；WEB-08 仅响应式布局，当前 loopback 部署不提供手机远程登录。真实设备支持边界见 [平台矩阵](../testing/platforms.md)。
