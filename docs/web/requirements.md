## 快捷输入的会话面板

以下要求已接入当前源码，验证边界见[本机持续聊天计划](../development/features/local-node-chat/plan.md)。WEB-12 的原文本编辑范围增加显式发送，Shift+Enter 换行、IME、内存草稿和进程隔离规则继续有效。

| ID | 要求 |
|---|---|
| WEB-CHAT-01 | 快捷输入保持多功能入口；发送聊天后自动展开消息区，复用同一输入框，箭头折叠/展开不取消生成，历史入口始终可用 |
| WEB-CHAT-02 | 按钮/Enter/Ctrl+Enter 显式发送，Shift+Enter 换行，IME 组合期间不发送；发送快照与新草稿分开，可靠 ACK 不清空后来编辑 |
| WEB-CHAT-03 | 聊天窗口失焦保持显示，不置顶且无固定模式；Esc/同键及系统关闭窗口显式隐藏但不取消，后台回复不抢焦点，旧消息滚动位置保持 |
| WEB-CHAT-04 | 新对话、简单会话列表、最近一页和更早历史、可见的发送/生成/保存状态、停止按钮；UI 重建从权威历史与运行状态恢复 |
| WEB-CHAT-05 | 文本/Markdown/代码块安全展示并可复制；禁原始 HTML、自动远程资源和危险 URL，不从模型文本推断任务状态；内容块为未来媒体保留类型边界 |

- WEB-CHAT-06：发送后立即显示本地气泡并清空输入区显示，待确认原文保留为有界恢复快照；明确拒绝时仅在用户尚未继续编辑的情况下恢复原文，未知送达保持核对且不自动重发；按稳定身份合并原生历史；正常接收无额外成功标签，拒绝、送达待确认和回复失败分别提示。
- WEB-CHAT-07：Enter 发送、Shift+Enter 换行、Ctrl+Enter 兼容发送；输入法确认候选不发送，Esc 保持隐藏。
- WEB-CHAT-08：仅可见正文未完整时显示完整读取入口；非展示字段的截断不触发按钮，全文读取失败保留原预览。
- WEB-CHAT-09：正常聊天不显示输入 placeholder、草稿生命周期说明或回复完成标签，左下角只提示 Esc 隐藏；保留需要处理的发送、生成、保存及输入错误。
- WEB-CHAT-10：用户发送后立即显示一个至三个点循环的“正在回复”，正常发送确认、准备与生成阶段保持同一提示，正常完成清空；隐藏停止动画，减少动态效果和读屏可用，不增加状态请求。拒绝、送达未知、生成或保存异常仍单独提示。
- WEB-CHAT-11：本地离线渲染常用行内/块级 LaTeX 数学公式，原文保存与复制不变；代码和价格不误渲染，未闭合/错误/超限保留源码；禁止外部资源与危险命令，渲染和缓存有界。
- WEB-CHAT-12：顶部品牌及空白区可拖动，按钮/正文/输入不拖动；同屏隐藏重开和内容尺寸调整保留本次宿主生命周期内的位置，跨屏及 DPI/工作区变化保证窗口可操作；公共语义可由不同桌面平台适配。

WEB-CHAT-09—12 及失焦策略调整的实施状态、详细验收标准见[聊天桌面体验计划](../development/features/chat-desktop-experience/plan.md)。

- WEB-CHAT-13：发送和运行期间的临时提示不改变消息区高度；发送/运行状态置于固定高度状态区，正文区只承载会话消息；提示词注入与应用状态不在聊天界面显示。验证见[发送稳定性与完成提醒](../development/features/chat-completion-attention/plan.md)。

- WEB-CHAT-14：启动和生成期间可继续新建、切换和发送；正常发送统一显示普通消息气泡与“正在回复”，不展示待发数量、准备阶段或取回/取消按钮。仅实际失败后出现异常提示和必要恢复入口；保留停止与显式继续。队满保留新草稿，宿主重建恢复消息，迟到状态不覆盖当前选择或新编辑。详见[聊天操作队列](../development/features/chat-operation-queue/plan.md)。

## WEB-CHAT-15：聊天连接状态

对话 ID 后显示“连接中 / 已连接 / 无法连接”，分别用黄色、绿色、红色文字；不附失败原因。展开面板开始连接，初始化和重连归入连接中；配置缺失、认证失败和其他连接失败统一归入无法连接。已连接依据 Agent 握手和现有运行结果，不为判断状态额外请求模型。排队、回复及暂停使用原有发送反馈，不增加连接状态。详见[连接状态计划](../development/features/chat-connection-status/plan.md)。

## WEB-CHAT-16：收起态输入自动高度

收起态空草稿显示一行，按文本实际视觉行数增长或回缩，包含自动折行、显式换行和尾部空行；最多显示十行，超出实际可见空间后提供可拖动的纵向滚动条，文本仍遵守原有字节上限。十行以内的正常换行扩高过程不闪现滚动条或顶部残缺文字；等待窗口增高时保持文本顶部稳定，工作区确实限高时仍可滚动并显示末尾光标。默认恰好容纳，内部预留额外一行的体验调节能力；两种策略均在清空后回到一行。展开态保持原有高度和滚动行为，收起后以当前草稿重算。布局覆盖编辑、撤销、恢复和回填，保持 IME、提交快照与修订语义；辅助确认区另计高度，工作区不足时提前滚动。设计与验收见[自动高度计划](../development/features/compact-input-auto-height/plan.md)。
